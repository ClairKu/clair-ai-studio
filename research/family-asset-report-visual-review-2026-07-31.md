# 家庭资产分析规划报告视觉方案评审

- 日期：2026-07-31
- 评审对象：Figma「家庭资产分析规划报告视觉」
- 评审范围：页面「2026.7.30 财富报告 pdf 视觉方案设计」
- 设计状态：方向稿；源稿注明文案与间距将在方向确定后细化

## 结论

推荐采用“视觉四做母版，强化品牌做系统”的组合方向。

- 视觉四（高端尊享）承担封面、致信、章节页、结尾页等叙事节点，建立付费服务的价值感、专属感和陪伴感。
- 强化品牌风格承担目录、数据内页、页眉页脚、信息卡片、图表和辅助图形规范，建立品牌识别与规模化生产能力。
- 不建议二选一，也不建议整份报告持续使用深色大图。高端感应来自可信、克制、专属和长期主义，而不是装饰堆叠。

## 评审维度

本次采用 5 个产品决策维度等权比较，分数用于相对比较，不是用户研究结论：

1. 价值感：是否匹配付费顾问服务与高净值家庭预期。
2. 信任感：是否稳健、专业、克制，避免营销感和工具感。
3. 品牌识别：是否形成且慢 / 盈米独有的视觉资产。
4. 长文可读：目录、正文、图表和建议页能否持续阅读。
5. 模板延展：能否覆盖财务规划、持仓分析、投资规划等系列报告。

## 方案判断

### 视觉四 · 高端尊享

优点：

- 夜海、光环、家庭、帆船和灯塔形成守护、陪伴、航向和长期主义的叙事。
- 四类报告封面有区分又保持统一，系列化能力强。
- 章节页与结尾页有仪式感，最符合“客户愿意收藏的专属报告”。

风险：

- 图像素材容易落入高端财富管理的常见意象，需要统一摄影、光源和视平线规则。
- 如果深色页面比例过高，会影响正文阅读、打印成本与 PDF 体积。
- 暖金应仅用于关键内容，不应扩大为“奢侈品画册”风格。

### 强化品牌风格

优点：

- Logo 辅助曲线、蓝色色阶和大数字层级具有稳定的品牌识别。
- 目录、正文和结尾页秩序清晰，适合批量生成与多报告扩展。
- 白底与浅蓝卡片更适合长文、图表和解释说明。

风险：

- 单独作为整套主视觉时，价值感和专属感弱于视觉四。
- 大面积品牌蓝如果缺少叙事画面，容易接近企业宣传册。
- 辅助图形应控制占比，避免大面积水印或重复堆叠。

### 视觉二 · 深蓝极简

成熟、安全、稳重，是可用备选；但系列封面之间的情绪区分和品牌记忆点弱于视觉四。

### 视觉三 · 科技金融

数字金融和工具属性明显，但 3D 发光资产容易弱化家庭财富规划需要的人情味、长期陪伴和可信感，不建议作为主方向。

## 推荐视觉系统

### 角色分工

- 封面 / 致信 / 章节页 / 结尾页：视觉四。
- 目录 / 正文 / 数据页 / 页眉页脚：强化品牌风格。
- 品牌蓝：导航、章节编号、图表重点与信息卡片。
- 暖金：报告等级、关键结论、核心数字，控制在约 3% 的视觉占比。

### 色彩比例

- 白与浅灰：约 65%。
- 深海蓝：约 20%。
- 品牌蓝：约 12%。
- 暖金：约 3%。

### 字体与语言

- 标题可使用宋体增强专业与人文感。
- 正文使用黑体保证屏幕与打印阅读。
- 统一英文报告名称，避免在不同报告中重复使用 `Asset Allocation Proposal`：
  - 财务规划报告：Financial Planning Report
  - 持仓分析报告：Portfolio Analysis Report
  - 投资规划报告：Investment Planning Report
