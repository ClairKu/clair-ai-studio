# 盈米 AI 开放平台商化收费路由

更新：2026-08-03
用途：报告第 18 章「商化准备」的内容源与证据边界。

## 一句话结论

稳定卖承诺，波动卖额度：个人稳定高频以订阅为主、资源包补充；企业波动调用以按量预付为主，稳定主链路再转企业年包。

## 场景路由

| 客群 | 用量波动 / 临时 | 用量稳定 / 可承诺 |
|---|---|---|
| 企业合同 / SLA | **企业按量预付为主**：API 接入、多工具混用、调用量波动，单位成本透明 | **企业年包为主**：稳定主链路、年度采购、并发与 SLA 要求明确 |
| 个人自助 | **资源包为主**：低频、临时、试用或订阅外扩容 | **个人订阅为主**：持续、高频、固定预算与月度权益 |

## 商化演进

1. 上线期：先验证交易与交付闭环——个人订阅为主，企业按量预付为主。
2. 稳定期：推动长期承诺——个人转年订，稳定企业转轻量 / 高阶年包。
3. 规模期：提升客单与保障——旗舰 / 定制年包、阶梯折扣与专属 SLA。

## 统一计量底座

- 当前 API 收费表：T1 / T2 / T3 标准单价为 ¥0.3 / ¥0.5 / ¥0.9 每次。
- 个人积分口径：T1 / T2 / T3 分别消耗 3 / 5 / 9 积分。
- 个人与企业套餐是在同一计量底座之上，对额度、有效期、并发和服务的不同封装。

## 方案参考与边界

- 个人订阅：单月、连续包月、按年；月度积分可结合登录、分享、邀请等激励补充。
- 个人资源包：用户提供的方案参考为 ¥9.9—¥9,999、1,800—2,500,000 积分、1 个月—2 年有效期。
- 企业年包：用户提供的方案参考为 ¥10 / 20 / 60 万年费、200 / 500 / 1,000 QPS，对应 POC / 小团队、日常主链路、高规模 / 多部门并行。
- 上述资源包、订阅包型与企业年包均标记为「目标态 / 方案参考」，不表述为已上线或已成交。
- 已确认需求证据只有「30+ 额度扩充与付费咨询」；不能外推为付费用户数、成交量或收入。

## 上线准备

- 个人：微信 / 支付宝支付、连续扣费、退款、到期提醒、积分账单。
- 企业：打款、合同、开票、对账、用量预警与 SLA。
