# 原始材料与证据审计

## 用户目标

用一张图表达盈米 AI 开放平台的关键行动，并明确两个不并列的模块：四个持续是平台核心运转与关键努力；两种接入模式是在平台之上的势能放大路径。完整关系为“四个持续 → 盈米 AI 开放平台 → 两种接入模式 → 更多群体 → 势能放大”。

## 势能放大模块：两种接入模式

1. 大厂 AI 平台接入。
2. C 端产品接入。

两种模式负责把开放平台沉淀的专业能力送入更多入口、产品与用户场景，不等同于平台内部的建设举措。

## 核心运转模块：四个持续

1. 持续建设：MCP、Skills、Agent。
2. 持续抢先：首个财富 MCP Server；首个理财测评集 / 投顾智能立体模型；首个投顾龙虾 OpenClaw；首批千问 MCP / A2A 接入合作商。
3. 持续合作：阿里云 / 百炼、百度、火山引擎 / 扣子、华为 / 小艺、夸克 / 千问、腾讯 / 微信 / WorkBuddy、智谱、金融机构。
4. 持续曝光：内容传播、媒体声量与行业活动。

## 传播与行业交流

- 盈米 AI 开放平台公众号原创文章视频 50+，总阅读量 3 万+次，全网渠道发布 300+篇。
- 盈米 AI 相关报道 8,965 篇，其中盈米 MCP 3,329 篇；全网互动 300 万+，浏览 1,000 万+。
- 活动 10 场+，交流机构 30 家+。

## 证据状态

- `confirmed`：两大模式、MCP / Skills / Agent 三层建设、合作生态与传播主指标，可在用户材料及现有阶段成果源稿中定位。
- `confirmed by supplied material`：四项“首个 / 首批”与活动、交流机构数量按用户本次提供材料原样呈现。
- `missing`：活动、交流机构数量的统计区间、去重规则与明细；传播监测平台和完整统计方法。
- `inferred`：建议用“有效接入、复用率、线索归因”继续验收四个持续的经营价值。

## 中心判断

盈米 AI 以四个持续作为核心运转引擎，把能力、先发机会、生态伙伴与品牌声量持续注入开放平台；平台再经由大厂 AI 平台接入与 C 端产品接入两条路径触达更多群体、放大势能。下一步应把“接入与曝光”继续转成“有效使用、可复用合作与可归因增长”。
