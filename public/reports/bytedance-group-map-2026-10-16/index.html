02 / 整个集团怎样分工

用七块业务地图理解，别继续套用2021年的“六大BU”。

2021年的抖音、大力教育、飞书、火山引擎、朝夕光年、TikTok六大板块是历史起点。2026年AI组织与ToB整合已改变旧边界。下面是业务视图，七块分组不表示公司正式公布了“七大事业部”。[6][8][12]

国内内容与交易

产品线：抖音主站 / 极速版 / 直播 / 搜索 / 开放平台；抖音电商；抖音生活服务；巨量引擎 / 穿山甲 / 巨量星图；今日头条 / 西瓜视频 / 番茄小说 / 红果短剧。

业务与团队：以用户时长、广告、交易和本地商户经营为核心。内容、广告、电商与生活服务存在协同，但有各自业务负责人。

关键人：张利东；韩尚佑、魏雯雯、浦燕子、赵修影、张超等。国内主干名单主要依据2024报道，逐人见证据日期。[4][5]

海外内容与商业化

产品线：TikTok、TikTok Shop、海外广告；CapCut、Lemon8等海外产品。BytePlus面向海外企业提供技术服务。

业务与团队：TikTok是海外产品与业务体系；美国USDS合资实体负责特定安全、数据与审核职责，不能等同于整个全球TikTok。CapCut等不据产品名强行画入同一管理线。

关键人：TikTok全球CEO周受资；USDS合资CEO Adam Presser。[2][29]

AI模型与数据

产品线：Seed：语言、图像、视频、语音、Agent、长期研究；AI数据与安全：跨模态数据供给与质量。

业务与团队：模型研究、面向产品的模型优化、数据服务是不同职责；Seed不等于豆包App产品团队。

关键人：Seed吴永辉；基础模型数据/强化学习/Work/Chat负责人；AI数据与安全王赢磊。[10][11][12][14]

AI应用与生产力

产品线：豆包 / 豆包工作；飞书 / Lark；扣子 / 扣子编程；TRAE IDE / CLI；其他AI创新应用。

业务与团队：2026年重组把产品能力向豆包体系集中。普通助手、办公Agent、开发平台、协作套件仍需分开识别。

关键人：应用上层朱骏（2025任命链）；豆包赵祺；豆包工作童遥；飞书谢欣。[8][9][18]

企业云与AI商业化

产品线：火山引擎：云基础设施、数据、音视频、AI服务；火山方舟：模型服务平台；创造力服务平台：ToB市场/销售/客户服务。

业务与团队：火山引擎是企业服务大盘，方舟是其中一项平台产品。统一销售不等于模型研发与所有产品都归火山。

关键人：谭待；飞书商业负责人林婵、战略市场负责人史志隽的汇报线据7月报道调整。[7][15][16]

创作工具与智能硬件

产品线：剪映 / CapCut / 即梦AI；PICO XR；豆包手机助手与Ocean相关硬件团队；Ola Friend等历史硬件探索。

业务与团队：创作应用与Seed生成模型存在能力关系；PICO与手机助手是不同硬件方向。手机由中兴努比亚与字节合作。

关键人：张楠与剪映业务关联源于2024报道；PICO李晓凯；Ocean刘成城为6月报道口径；努比亚倪飞。[4][25][27][28]

垂直业务与组合调整

产品线：懂车帝；教育与学习产品；朝夕光年及游戏组合。

业务与团队：懂车帝独立公司与融资/IPO计划需区分；沐瞳已公告出售交易，交割状态须另核；教育不能照搬2020年的陈林名单。

关键人：懂车帝、教育、游戏现行总负责人本轮未取得足够证据，留作缺口。[30][31][35]

集团管理层与共享职能：公开到什么程度？

官网目前董事会列示梁汝波为董事长；2026年公开报道继续称其为字节CEO。董事名单还包括Arthur Dantchik、William E. Ford、Xavier Niel、Neil Shen。张一鸣是创始人，不能画成现任CEO；张利东的抖音集团董事长身份也不能上移为全球字节董事长。[2][8]

集团还存在技术基础设施、推荐与算法、财务、HR、法务、公共事务、安全等共享职能。本轮不把不完整的网上名单拼为完整高管层，不填报未经2026年证据核实的CFO/HR/法务现任负责人。杨震原在PICO调整报道中承担上层技术管理角色；完整共享职能汇报链待公司确认。[28]

05 / 结构究竟怎样变了

从多个产品各自推进，转向模型、产品与商业化集中。

2021.11

以抖音、教育、飞书、火山、游戏、TikTok划分。[4]

适合解释历史；不能视为2026现行完整组织。

香港及境内主体更名

全球ByteDance顶层名称与国内主体名称并存。
2024.02

此前的统一CEO角色退出；五条业务线分别承担职责。[4][5]

最值得抓住的变化（分析）

对企业合作方而言，字节正在减少产品与销售的分散：办公Agent、协作上下文、模型服务可以一起讨论。但统一集团关系不自动带来统一商务承诺，应该要求一名对结果负责的牵头人，明确跨团队分工。

  3. 在哪些账号、套餐与地区实际开放？
