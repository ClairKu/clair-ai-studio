五小分组指标数据公式口径盘点（index / macro-indicator / fund-select / fund-manager / world-news / research-report）

实测日期：2026-09-02。实测调用共 14 次，全部成功（0 次报错重试）。 附件：agents_out/fund_select_config_STOCK.json（STOCK 指标配置全量原文 463 条）、agents_out/fund_select_STOCK_indicators_full.md（全量表格）、agents_out/fund_select_STOCK_base_indicators.md（按周期归并后 191 个基础指标清单）。

1. index（6 个工具）

1.1 get_databoard_index_performance_index_valuation ⭐（实测 PE/PB/ERP 各 1 次，000300，2020-01-01~2026-08-31）

PE / PB 出参（data[].statistics，值为字符串，6 位小数）：

  • percentile_0 / 25 / 50 / 75 / 100：区间内 PE(PB) 的 0/25/50/75/100 分位对应的估值原值（即 min/Q1/中位/Q3/max），不是"当前值处于第几分位"的分位点排名。
  • current_value：最新 PE(PB) 原值。000300 PE 实测：min 10.29 / 中位 12.60 / max 17.46 / 当前 13.77；PB：min 1.15 / 中位 1.42 / max 1.92 / 当前 1.45。
  • data_points_count：参与统计的样本点数。
  • 分位窗口 = 调用方传入的 start_date~end_date，没有固定 5 年/10 年默认窗口——口径由使用者决定，报告引用时必须注明区间。

ERP 出参：mean_plus_2std / mean_plus_1std / mean / mean_minus_1std / mean_minus_2std / current_value，即 μ、μ±1σ、μ±2σ（工具说明：样本标准差）。

  • 公式（工具描述明示）：ERP = 1/PE − 10 年期国债收益率；bond_reference_type=domestic（本国国债）/us（美国国债），仅 ERP 必填。
  • 单位：小数（0.055761 = 5.58%）。反算验证：1/13.7657 − 0.055761 ≈ 0.0169，即隐含 10Y 国债收益率 ≈1.69%，与当前中债 10Y 一致，公式核实成立。
  • 特殊指数自动做 ETF 映射（如 SPX→SPY）。

⚠️ 频率疑点（重要）：同一区间 2020-01-01~2026-08-31，PE/PB 的 data_points_count=2435 = 该区间的自然日总数（精确相等），而 ERP=1662 ≈ 交易日数。即 PE/PB 分位数是在按自然日填充（含周末节假日 forward-fill）的序列上算的，ERP 的 μ/σ 是在交易日序列上算的。自然日填充不会改变 min/max，但会让分位数向"持续时间长的估值水平"加权，与常见"交易日分位"口径有细微差异。

1.2 getLatestIndustryWeightSummary（实测 000300，默认参数）

  • 出参：data[] 每项 industryName / stockCount / totalWeight。
  • totalWeight 为 0-1 小数（电子 0.1807=18.07%），全行业合计 ≈1.0。
  • 默认行业体系为中信（21 传参代码，实测返回 26 个中信一级行业）、默认一级层级、默认最新报告期。
  • ⚠️ 响应不回显所用 recordDate / industryClassCode / industryLevel，引用时无法从出参自证口径，需在入参侧固化。

  • get_databoard_index_performance_index_trend：收盘价走势；is_normalized=true 时首点=1、后续为相对倍数（累计净值倍数口径，非涨跌幅%）。
  • searchIndex：分页模糊搜索；searchKey 含逗号自动转多代码精确 IN；返回 assetCode/assetName/assetFullName/assetCodeYm（盈米带后缀代码，如 000300.CSI）/beginDate/endDate/三级分类/发布机构。已验证可用。

2. macro-indicator（4 个工具）

2.1 indicatorSearch（实测 keyword=CPI, type=MACRO）

  • 出参每条：indicatorCode（纯数字字符串，如 2012）/ indicatorName（Wind 风格中文名"美国:CPI:季调:同比"）/ frequency（"月"/"季"等；INDEX 类固定"日"）/ unit（"%"等；INDEX 类固定"点位"）/ startDate / endDate。
  • CPI 命中 20 条，含美日各国、核心/分项、同比/环比、季调/未季调多口径并存；存在重复指标（2002 与 2147 都是"日本:CPI:同比"，起止日完全相同）——同名不同源，选用时需固定 code。

2.2 getIndicatorSeries（实测 code=2012 MACRO，2026-01-01~08-31）

  • 出参：indicator_code/name/type/frequency/unit/start_date/end_date + series_data[]（record_date, value 字符串 6 位小数）。
  • 月频 record_date = 自然月末日（2026-02-28、2026-06-30）；value 单位随 unit（此处 %，2.4 即 2.4%，注意与小数口径的组不同）。
  • 支持 INDEX/MACRO 混批，最多 50 个。

2.3 汇率两件套（未实测，凭 digest）

  • getForeignRatesTimeseries：日线收盘汇率 exchange_price（可为 null=当日无数据）；D 货币（ori）/F 货币（ex）方向要留意，digest 未说明是"1 单位 ori 兑多少 ex"还是反向——方向口径待验证。

3. fund-select（5 个工具）⭐核心

3.1 public_fund_indicator_config_query（实测 assetType=STOCK, configId=-1）

返回 463 条指标（compositeIndicators 空）。字段：id/indicatorId/classify/name/code/dataType/upgradeInterval/allowEditShow/allowEditFilter/defaultScoreDirection/remark/unit/sort/...。

  • classify 分布：BASE 109 / TRADE 95 / TAG 44 / INCOME 117 / SCORE 60 / RISK 38。
  • dataType：NUMBER 240 / STRING 205 / DATE 18。
  • unit 字段：447 条为空、10 条"是否"、6 条"直接加%"（仅盈米各项费率）。⚠️ 收益/回撤/波动类 NUMBER 指标 unit 为空，但实测值为小数（0.2=20%）——量纲不在配置里，靠约定。
  • 周期化命名：多数指标带 _1y/_2y/_3y/_5y，收益风险类另有 _since_appointment（现任经理任职以来）；筛选/展示时周期经 screenerIndicatorDetail 的 code=label 维度传（1y/2y/3y/5y/ytd/since_appointment）。

归并后 191 个基础指标要点摘录（全文见 fund_select_STOCK_base_indicators.md）：

BASE（基础/持仓特征）：

  • 基金代码/名称/成立日/成立年限/是否定开/现任经理/任职开始日（口径：任职最长的现任经理）/是否主基金。
  • manager_summary 经理综述：启明投研 AI 生成，"蓝色=盈米内部研究、红色=全市场研究"。
  • 仓位：a_stock_ratio_avg（A股仓位=股票仓位−港股仓位，区间报告期均值）、hk_stock_ratio_avg。
  • 行业特征：rotation_ratio_avg 行业轮动程度（区间内板块间调仓幅度均值，少于 2 个报告期不计算）、第一/前二重仓行业及占比、stability_1st/top2 重仓行业稳定度（=该行业为区间重仓的期数占比）。
  • 风格特征：growth_score/value_score（按成长/价值类股票平均持有比例计算的得分）、价值/深度价值/成长/新兴成长四档风格占比。
  • 三套对比指数：行业对比指数（index_code）、风格对比指数（style_index_code）、市场适应性指数（adapt_index_code）——能力类指标分别挂靠。
  • 评估窗口自述字段：start_date/end_date（报告期窗口）、eval_start_date/eval_end_date（能力指标计算窗口，"首个报告期~最近一个交易日"）。

TAG（标签，44 条）：

  • fund_type：行业主题/行业集中/行业轮动/行业均衡/无行业特征 五档。
  • style：由成长评分与价值评分相对关系判定（新兴成长/成长/均衡/价值/深度价值——option_query 实测枚举为：价值、均衡、成长、新兴成长、深度价值）。
  • 能力标签统一规则：排名前 5%（行业主题/行业集中型基金放宽为前 10%）打标——领域超额/风格超额/个股超额/进攻/防守/控回撤/低波动/绝对收益 8 个标签。

INCOME（收益能力）：

  • interval_return/ann_return（区间收益/年化收益）、sharpe 年化夏普、calmar 年化卡玛、prob_positive_return 持有3月正收益概率。
  • information_ratio：基于行业对比指数计算。
  • upward/downward 进攻/防守能力：指数上涨/下跌阶段基金相对指数的年化超额收益，对比指数=市场适应性指数，收益率按周频计算。
  • ann_alpha_sector/ann_alpha_style：相对行业/风格对比指数的年化超额。
  • ann_stock_selection_return 个股选择能力：持有股票相对行业指数超额收益的加权平均的几何年化值。
  • 同类排名 rank_*_class："行业主题/行业集中基金→同行业对比指数为同类；其余→同风格对比指数为同类"。
  • *_wavg 标准化系列（标准化年化收益/波动/回撤/绝对收益）：remark 均写"近1年…"，疑为跨周期加权到 1 年口径（见疑点）。

SCORE（评分）：

  • score_total 总评分 = 10 个评分的均值：标准化年化收益、标准化年化波动、标准化最大回撤、标准化绝对收益、进攻、防守、领域超额、风格超额、个股选择、信息比率评分。
  • 基础评分公式（remark 原文）："标准化年化收益率相对同类最差值的超额 ÷ 基准值相对同类最差值的超额"（波动/回撤/绝对收益同构）。
  • score_*_rank 系列 = 对应评分的百分位排名。

RISK：年化波动率、最大回撤（负小数）、最大回撤区间（STRING）、修复时长、次大回撤及区间；均有 since_appointment 周期。

TRADE（95 条）：盈米/中航/粤开/腾安/中银/万联/国元/腾安(偏债) 8 家代销渠道的费率与申赎限额；仅盈米费率是 NUMBER（unit=直接加%），其余渠道全为 STRING 展示字段（filter=0）。

8. 疑点汇总

  1. PE/PB 分位在自然日填充序列上计算（区间点数=自然日数 2435），ERP 在交易日序列（1662）——两者样本基不一致，PE/PB 分位与"交易日分位"惯例有偏差。
  2. 估值分位无固定回看窗口，完全由入参区间决定；不同调用方取 3y/5y/10y 会得出不同"分位"，对外引用必须带区间。
  3. 行业权重接口不回显 recordDate/行业体系/层级，出参无法自证口径。
  4. fund-select 配置 unit 字段基本为空（447/463），收益/回撤/波动实际是 0-1 小数，量纲全靠约定；直接加% 仅用于盈米费率 6 条。
  5. *_wavg"标准化"系列 remark 一律写"近1年…"（含 2y/3y/5y 版本也这么写），标准化的确切加权方式（是否多周期加权折算）文档未说明。
  6. 评分公式"相对同类最差值的超额 ÷ 基准值相对同类最差值的超额"中的**"基准值"定义未给出**（疑为对比指数同指标值）。
  7. STOCK 的 compositeIndicators 为空——合成指标 ci_{id} 能力存在但默认字典无内容，BOND/FIXED_INCOME_PLUS 是否有未测。
  8. getManagerFund 的 netAsset（份额规模）实测恒等于 totalNetAsset，份额口径疑似回填错误；且经理维度无年化回报，需借 fund-select 的 since_appointment 周期或 fund-analysis 组。
  9. 经理对标指数是 Wind 基金指数（885013.WI 等，按二级分类挂靠），不是招募书业绩比较基准，做超额时勿混用。

  11. world-news：get_finance_news_live 的 limit 上限三处描述矛盾（50/1000/10000）、includeTags 默认值两处矛盾；getFinCalendar 同一事件重复且 importance 不一致；数值全是含单位字符串。
