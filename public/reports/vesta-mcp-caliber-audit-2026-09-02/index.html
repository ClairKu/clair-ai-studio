三、分组指标口径盘点（浓缩版，全文见各明细文件）

3.1 portfolio-analysis（组合分析，31 工具）——指标最重

核心指标（performance_by_code 实测 27 字段）：区间/年化收益、年化波动、最大/第二大回撤（含起止/修复日与天数）、下行波动、VaR、夏普/索提诺/卡玛、M2/跟踪误差/信息比率、beta/alpha/treynor。

已核实的公式口径（★=本体生产日志/数值反推验证，误差<0.01pp）：

  • ★年化收益 = (1+R)^(252/N)−1，N=区间交易日数；年化波动率 = 日收益标准差×√252；夏普/索提诺 rf = 固定 1.5%（非国债联动，两组样本反推均得 0.0150）；卡玛 = 年化收益/|最大回撤|（组合侧为教科书定义，不含 rf）；VaR = 历史分位数法（非参数正态）。
  • ★归因输出是 Brinson 三效应外壳，底层实为因子回归归因：把组合收益回归到 23 个细类因子，按大类聚合成配置/选择/交互三效应——实测三效应之和 = 超额收益（0.0958936 严格闭合）；区间交易日数必须 ≥23（回归自由度），否则报"因子数据不足"；按调仓区间分段。另有五大类收益分解，加总=总收益。
  • ★组合净值来源：portfolios/sync → fund_daily_liquidation（成分基金逐日清算）→ nav_fitting 三段管线拟合，调仓日切段。
  • 胜率："≥0 算赢"实锤（positive_ratio 与 day_win_rate 相等）；周/月胜率是 5/21 交易日滚动窗口，非日历周月。
  • 收益分布：滚动收益假设正态，21 点 avg±k·std；⚠️ probability 字段实为正态密度值（φ(0)=0.3989），不是概率。
  • 贡献：贡献率=权重×日收益率；分类收益率=Σ贡献/Σ权重（描述明示）。
  • 基准：组合自带业绩基准自动参与（comparison 自动追加 BM<po_code> 线；未传基准也算出 M2/TE/IR）。
  • 组合类型：VES 前缀=VESTA 自建（费后净值，ying99_vesta 表）；PO_ZH/PO_SI/PO_MOM/PO_AM=PMS 组合（ying99_pomodel，含费与否未说明）。
  • 风险评分：uaap-gateway 回归模型（risk_score 84.83 + R²/残差方差/标准误），effectiveDate 月频快照疑似。

最大坑：①benchmark_performance 传 000300.CSI 全 null 不报错；②realtime 系列（by_adjustment 性能/分布）描述明示净值拟合当前为 Mock 数据——结果不可用于正式结论；③调仓统计实测 cumret_net_excess(0.2990) > cumret_excess(0.2962)，净超额>毛超额，净/毛定义疑似反直觉待确认。

3.2 fund-analysis（基金分析，20 工具）

  • 收益：复权净值区间涨跌幅（分红再投）；get_fund_return_metrics（百分数）与 getIntervalReturnComparison（小数）同源 ×100 对应。
  • ★成立以来年化 = (1+R)^(365.25/N)−1，N=自然日（本体两只基金样本反推核实）——⚠️ 与组合侧的 252 交易日基数是两套年化口径，同网关并存。
  • 无风险利率 = 1.5%/年：子代理由 sharpe×vol = calmar×|mdd| = geomReturn−rf 三式联立反推 ≈1.5%，本体在组合侧独立反推得 0.015000——双路互证，固定 1.5% 实锤（但无任何文档）；PerformanceComparison 的 calmar 是含 rf 的变体（分子=年化几何收益−rf），与组合侧教科书 calmar 不同。
  • queryFundPerformance：17 项指标（含 Alpha/Beta/Treynor/M2/TE/IR + 同类排名），基准=入参指数（需 .CSI 后缀，裸码报 0413"计算任务异常"）。
  • 债类指标：杠杆=总资产/净资产；集中度=重仓债市值/债券总市值；久期仅年报/半年报有值（利率敏感性分析法）；同类=招银基金分类（描述明示）；avg 行用哨兵日期 9999.12.31。
  • 久期双轨：报告期披露（110007 = 6.07 年）vs 日频测算 duration_estimation（~1.78 年）严重背离，用前必须对齐来源。
  • 占比普遍三分母并存：占总资产/占净资产/占债券市值——跨口径不可直接比。
  • 估算净值缺口 getFundEstNvGap：持仓结构 semiannual(全持仓)/quarter(重仓)，估算净值 vs 实际净值归一作差，测隐性调仓/风格漂移。

3.4 index / macro-indicator（指数与宏观）

  • 估值分位口径（重要）：PE/PB 返回入参区间内估值原值的 0/25/50/75/100 分位（即 min/Q1/中位/Q3/max），不是"当前处于第几分位"的排名；无固定回看窗口，完全由调用方区间决定——对外引用必须带区间。
  • ERP = 1/PE − 10Y 国债收益率（工具描述明示 + 反算核实：隐含 10Y≈1.69% 与中债一致），返回 μ、μ±1σ、μ±2σ 通道，小数量纲；bond_reference_type 可选本国/美国国债。
  • ⚠️ 样本基不一致：同区间 PE/PB 样本点数=自然日数（2435，forward-fill 填充），ERP=交易日数（1662）——PE/PB 分位与常规"交易日分位"有偏差。
  • 行业权重：默认中信一级、最新报告期，totalWeight 0-1 小数合计≈1；出参不回显 recordDate/体系/层级，无法自证口径。
  • 宏观指标库：indicatorCode 纯数字，月频 record_date=自然月末，unit 内嵌（%）；存在同名同区间重复 code（2002/2147 均"日本CPI同比"）。

3.5 fund-select（基金优选筛选器）——指标定义的金矿

public_fund_indicator_config_query 一次返回 463 条指标配置（STOCK 面板：BASE 109/TRADE 95/TAG 44/INCOME 117/SCORE 60/RISK 38），remark 即公式口径原文。关键公式：

  • 进攻/防守能力 = 指数上涨/下跌阶段基金相对市场适应性指数的周频年化超额收益。
  • 个股选择能力 = 持有股票相对行业指数超额收益的加权平均的几何年化值。
  • 总评分 = 10 个子评分的均值（标准化年化收益/波动/回撤/绝对收益 + 进攻/防守/领域超额/风格超额/个股选择/信息比率）。
  • 子评分 = "指标相对同类最差值的超额 ÷ 基准值相对同类最差值的超额"（"基准值"定义缺失）。
  • 能力标签 = 排名前 5%（行业主题/行业集中型放宽前 10%）。
  • 同类规则：行业主题/集中型→同行业对比指数为同类；其余→同风格对比指数。
  • 三套挂靠指数并存：行业对比指数 / 风格对比指数 / 市场适应性指数。
  • A股仓位 = 股票仓位 − 港股仓位（区间报告期均值）。
  • 筛选实测：收益/回撤全是 0-1 小数（ann_return_1y=1.89 即 189%），阈值也按小数填；但配置表 unit 字段 447/463 为空——量纲全靠约定，不在配置里。

3.6 fund-manager / world-news / research-report

  • 经理：managerYearTotal（管理年限 13.94）≠ securityExperiencePeriod（从业 18.16），描述明令勿混；对标是 Wind 基金指数（885013.WI 等，按二级分类挂靠），不是招募书业绩基准；规模单位元；netAsset 恒等于 totalNetAsset 疑回填错误；经理维度无年化回报字段（需借 fund-select 的 since_appointment 周期）。

五、疑点与缺陷总清单（按危险度）

🔴 高危（会算错数）

  1. queryChinaMacroFactors 全字段是 z-score 标准化值，字段名（govt10yBondYield/windAllAIndex）严重误导。
  2. 量纲不统一：get_fund_return_metrics 百分数 vs 全网关小数主流——100 倍错风险。
  3. 无效指数代码静默返回 null/空（benchmark_performance、comparison、beta 计算、RankTrend 错 freq、benchmark 错 type），与"无数据"不可区分。
  4. realtime 系列净值拟合明示 Mock 数据，结果不可用于正式结论。
  5. 收益分布 probability 是正态密度不是概率；重叠滚动窗口做 Z 检验统计上偏乐观。
  6. PE/PB 分位在自然日填充序列上计算（ERP 却是交易日）、且无固定窗口——引用必须带区间说明。

🟡 中危（口径黑盒或仅靠反推，引用需标注） 7. 年化基数两套并存：组合侧 252 交易日复利、基金"成立以来"365.25 自然日复利——已由本体反推核实但均无文档；rf=固定 1.5% 同样无文档；VaR 已确认历史分位数法但置信水平仍未披露。 8. 信号合成：A股 ≥3/4 规则已穷举破解，但风格仓位映射表、行业 8 分项权重、GRRI 构成资产仍黑盒；情绪指数/ERP 百分位窗口等因子计算在投研算法离线侧，不在服务代码里。 9. calmar 含 rf 变体、久期双轨背离、cumret_net_excess>cumret_excess 净毛反直觉、"同类"体系多头。 10. fund-select 评分公式中"基准值"定义缺失；*_wavg 标准化加权方式未说明。

🟠 接口缺陷（可报给 vesta 团队） 11. 🐛 queryChinaMacroFactors 传 columns 稳定 500；queryUsMacroFactors 文档默认列 coPosition 字段不存在。 12. 🐛 research-report 的 schema 与实际入参不符（必须包 req）；searchFundCodeAndName schema 分页字段名与实返不一致。 13. getManagerFund 的 netAsset 恒等于 totalNetAsset（份额口径疑回填错误）；getFinCalendar 事件重复且 importance 不一致；get_finance_news_live 的 limit 上限三处描述矛盾。 14. 行业权重出参不回显口径参数；backtest 不给净值基期；日期格式三种并存（yyyy-MM-dd / yyyy.MM.dd / 点分强制）。
