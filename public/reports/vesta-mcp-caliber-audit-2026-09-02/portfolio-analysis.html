口径盘点分组明细 · 2026-09-02

portfolio-analysis（组合分析，31 工具）指标数据公式口径盘点

盘点日期：2026-09-02。实测组合：ZH109248（慢牛长赢1号，PO_ZH 经典组合），区间 2025-01-01 ~ 2026-08-31。 实测调用共 14 次（含入参纠错重试）。实测覆盖 8 个工具，其余标注「仅 schema 盘点」。

通用口径（实测确认）：

  • 所有收益率/波动率/回撤/占比均为小数形式（0.48 = 48%），非百分数。
  • 日期格式 yyyy-MM-dd（部分工具兼容 yyyy.MM.dd）。
  • 数值字段多以字符串返回（如 "0.480601"），归因工具例外（原生 float）。
  • 组合类型识别：po_code 以 VES 开头 = VESTA 组合（费后净值，ying99_vesta.portfolio_composition_daily）；其他 = PMS 组合（净值，ying99_pomodel.portfolio_composition）。
  • 组合代码前缀枚举：PO_ZH 经典组合 / PO_SI 信号组合 / PO_MOM 资产包 / PO_AM 复合模型 / VES 自建。

3. get_portfolios_calculate_portfolio_risk_by_code ✅实测

实测出参：identifier(ZH109248)、risk_score("84.83085723")、r_squared(0.8256, 模型拟合度)、residual_variance(残差方差 5.99e-4)、standard_error(标准误 0.02499)、effectiveDate("2026-07-31")、status("success")、message。

4. get_portfolios_calculate_portfolio_win_rate ✅实测

实测出参：

  • win_rate: day_win_rate 0.567164 / week_win_rate 0.660804 / month_win_rate 0.716883。
    • 定义（描述明示）：日胜率=日收益率≥0 占比；周胜率=5 交易日滚动收益≥0 占比；月胜率=21 交易日滚动收益≥0 占比。注意是滚动窗口而非日历周/月。
  • 直方图 5 组，每组 6 个桶 {left, right, count_return}（区间边界小数、count 为天数）：
    • five_ten_thousandths_interval（±0.05% 步长）、one_thousandth_interval（±0.1%）、one_percent_interval（±1%）、two_percent_interval（±2%）：固定边界，首尾桶用 ±9999 表示开区间。
    • auto_interval：按数据 min/max 等宽 6 桶（实测 -0.082665~0.038608）。
  • day_return_ratio: positive_ratio/negative_ratio（正负收益天数占比，positive 与 day_win_rate 相等 → 胜率把 0 归为正，"≥0"实锤）。
  • 疑点：固定区间直方图的中间桶均只覆盖 ±2 步长内，尾桶吞掉大部分样本（如万五区间 155/212 落尾桶），做分布图需注意。

5. get_portfolios_compute_attribution_by_code ✅实测（Brinson 归因）

实测出参（float 原生数值，按调仓节点分段，每段一个对象）：

  • return_decomposition[]：start_date/end_date、equity/bond/commodity/alternative/cash（五大类收益贡献，小数）、total（区间总收益，实测 0.21838 与段内组合收益一致）。
  • attribution[]：start_date/end_date、benchmark_return、portfolio_return、excess_return（=portfolio−benchmark，实测 0.09589 严格相等）、三效应各含 equity/bond/commodity/alternative/cash/total：
    • allocation_effect 配置效应、selection_effect 选择效应、interaction_effect 交互效应。
    • 实测三效应 total 之和 0.0031866+0.0926338+0.0000733 ≈ 0.0958936 = excess_return，Brinson 三分法（BHB 模型，含交互项）闭合。
  • 方法：自动查调仓记录和组合自带业绩基准，按调仓节点分段。
  • 疑点：①分段结果是否几何/算术链接成整段未披露（实测单段无法验证）；②基准的大类拆分方式（各指数映射到哪个大类）未披露；③"另类"恒为 0 的分类规则未说明。

6. get_portfolios_calculate_return_distribution_by_code ✅实测（部分）

  • rolling_returns[]：{record_date, period_return} 日频滚动收益序列（字符串小数）。实测 3M 窗口从 2025-04-02 起出值 → 窗口按日历月回看（1月1日起投，首个 3M 点在 4 月初），非固定交易日数。
  • return_distribution[]（schema/描述口径，实测被 12000 字符截断未见）：21 个点位 {std_multiplier, return_value, probability}，= avg±[0,0.2,…,2.0]×std，假设滚动收益正态分布；probability 为正态密度值（示例 0.3989=φ(0)，即密度非累计概率）。
  • target_return_probability：Z 检验法计算滚动收益 ≥ target_return 的概率（target_return 小数形式，如 0.05=5%）。
  • 疑点：①probability 字段是密度值不是概率质量，直接当"概率"用会错；②滚动收益序列自相关严重（重叠窗口），基于它做正态检验/Z 检验统计上偏乐观，文档未提示；③rolling_returns 与 return_distribution 同返回易超长，MCP 侧无分页。

7. get_portfolios_comparison ✅实测

  • 入参口径（实测纠错）：benchmarks 数组元素为 {code, type}，type 枚举 小写 'fund'|'portfolio'|'index'|'manager'（digest 未写清，422 报错披露）。
  • 出参：
    • po_comparison_resp_list[]：每个标的一行，code（组合本身 / index_xxx / BM<po_code> 自动追加的组合业绩基准）+ 固定区间收益：last_week / last_2_week / last_month / last_3_month / last_6_month / last_9_month / last_year / last_2_year / last_3_year / last_5_year / from_setup_date（小数，非年化）。
    • po_comparison_price_group_resp_list[]：按日分组的归一化价格序列 {record_date, comparison_price_resp_list:[{code, record_date, price}]}，首日归一为 1.0（未显式传 zero_flag 也自动以 start_date 归一）。
  • 疑点：①区间收益字段是"截至查询 end_date 往回推"还是"截至最新交易日"未披露（实测 last_2_year 0.73 > last_3_year 0.50，为区间起点行情差异所致，非错误，但易误读）；②index_000300.CSI 全 null——指数代码校验不报错、静默返回 null。

  • 累计收益走势 + 单期超额序列（图表渲染用）。

14. get_portfolios_asset_allocation_by_code

  • 大类资产配置。asset_type：PMS（权益/固收/基金/现金及其他）或 VESTA（8 权益地域+6 固收细分）；ratio_type：TOTAL_ASSET（PMS 默认）/NET_ASSET（VESTA 默认）——两种分类默认分母不同，跨口径对比要显式统一；prefer_major_only 默认 true=仅用中报/年报穿透。
  • 疑点：默认 ratio_type 随 asset_type 变化，易踩坑。

15. get_portfolios_calculate_benchmark_performance ⚠️实测未通

  • 出参字段与 §2 完全同构（period_return…information_ratio + nav_list）。
  • 实测传 000300.CSI（单指数 1.0 权重）返回全 null 且不报错——指数代码解析失败静默吞掉。有效指数代码格式未能核实（index__searchIndex 500）。

16. get_portfolios_calculate_portfolio_correlations

  • 皮尔逊相关系数，基于区间日收益率序列（(当日净值−前日净值)/前日净值）；持仓恒用最新；interval_type 枚举 LAST_3_MONTH~LAST_3_YEAR（日历口径）；positive/negative 阈值过滤；penetrate 一层穿透，穿透权重=父权重×子权重、同基金权重累加；结果不含自相关。范围 [-1,1]。

17. get_portfolios_composition_analyze

  • 最新持仓权重 + 标的自身区间收益率（非贡献）；成立不足自动从成立日起算；穿透收益直接用标的实际收益、不加权。

18. get_portfolios_composition_holding_performance

  • 持仓 + 基金经理（managers: code/name）+ 8 个固定区间收益：last_tradeday/week/month/3month/6month/year/3year/ytd_return，小数。

19. get_portfolios_industry_allocation_by_code

  • 行业分布。industry_type：ZX 中信一级 / YM 盈米板块；perspective：FUND_ASSET 基金总资产 / EQUITY_ASSET 权益资产 / A_H_ASSET A+H 视角——分母三选一，数值不可跨视角比较；ratio_type 默认 TOTAL_ASSET；prefer_major_only 默认 true。

20. get_portfolios_interval_component

  • 区间控件数据：fixed_interval（近一周~近五年，只回存续内有效的）、calendar_interval（自然年/EST 成立当年/YTD）、setup_interval、market_style_interval（PF000001 牛熊/趋势/震荡区间）、saved_theme_interval（需 userId header）、调仓日期降序、last_business_day=当前日期。

21. get_portfolios_regular_invest_comparison

  • 定投 vs 一次性：freq=day/week/month/quarter（week 1-5 周几、day 1-28 号、month 1-3 季内月）；amount=constant（归一化 1 元）/multiple（区间倍率表）；非交易日顺延、同日多笔只算一笔。指标：累计收益率、最大回撤、平均回撤（回撤期平均）。
  • 疑点：定投收益率口径（简单收益 or 内部收益率 IRR/MWR）未披露——定投对比不说资金加权口径就没法解读。

22. get_portfolios_return_contribution

  • 日收益贡献。公式（描述明示）：日收益率=(最新净值−前日净值)/前日净值；收益贡献率=权重×日收益率；分类贡献=成员贡献加总；分类收益率=贡献/权重。view_type：HOLDING（一级持仓+二级穿透，加权权重=一级×二级）/CATEGORY（展平单基按 PMS 分类归集，无分类归"其他基金"）。二级穿透只一层。

23. get_realtime_benchmark_nav_calculator

  • 一篮子指数加权基准净值：各指数归一到 1.0 后按权重加权求和（权重和必须=1.0）；include_drawdown → drawdown=(当前净值−历史最高)/历史最高（≤0）；include_interval_return → last_week/last_month/last_3_month/last_6_month/last_year/ytd/from_setup_date。
  • 疑点：加权是"归一后价格加权"= 每日不再平衡的固定份额法还是每日再平衡，描述写"归一化后按权重加权求和"更像买入持有不再平衡，未明示。

  • ⚠️描述明示："组合净值拟合当前使用 Mock 数据，后续对接真实净值拟合方法"——该工具（及 §25）结果可信度存疑，重大口径疑点。

疑点汇总（跨工具）

  1. 年化因子未披露：annualized_return/volatility 用 252 还是 365，全组无说明。
  2. 无风险利率未披露：夏普/索提诺/Alpha/Treynor/M2 全依赖 r_f，取值与更新方式无文档。
  3. VaR 口径未披露：置信水平（95/99）、方法（历史模拟/参数法）、期限（日/区间）均无说明。
  4. 指数代码命名空间是黑盒：000300.CSI 在 comparison/benchmark_performance/beta 计算中均静默失效（返回 null 不报错）；index__searchIndex 又 500，无法核实有效格式。无效指数不报错是最危险的坑——用户会把 null 当"无数据"。
  5. PMS 组合净值含费与否未说明（VESTA 明确费后）；跟踪误差是否年化未说明。
  6. realtime 系列（§24/25）净值拟合明示为 Mock 数据，结果不可用于正式结论；§28 nav_calculator 是否同一 Mock 引擎待确认。
  7. 调仓统计的"超额"基准不明（§8/11），且实测 cumret_net_excess > cumret_excess，净/毛定义疑似反直觉，需与算法方核对。
  8. 收益分布的 probability 是正态密度值（φ(0)=0.3989），不是概率质量；且重叠滚动窗口做 Z 检验有统计学缺陷，文档无提示。
  9. 多段归因的链接方式未披露（几何/算术）；基准指数→五大类的映射规则未披露。
  10. schema 不统一：po_code vs poCode；products{prod_code,prod_type,weight} vs positions{code,weight}；日期 yyyy-MM-dd vs yyyy.MM.dd（§29 强制点分）；comparison 的 benchmarks type 枚举必须小写（digest 未写，422 才暴露）。
  11. 资产/行业占比默认分母随参数漂移：PMS 默认总资产、VESTA 默认净资产；行业三种 perspective 分母不同，跨口径数字不可直接比。
  12. 定投对比收益率口径未披露（简单收益 vs IRR/资金加权），影响解读。
  13. searchPortfoliosByName 的 startDate/endDate 恒 null；风险分 effectiveDate 滞后（2026-07-31），更新频率未说明。
