规模走势

亿元 · 月末时点 · 颜色=维度 · 实线=全口径 AUM · 虚线=柜台投顾口径

实线为全口径 AUM（dwd combine ROOT 层综合资产，含在途 / 未结算资金 / 钱包；深藏青=公司全部 broker、浅蓝=蜂鸟机构直连 0000、且慢蓝=且慢 0008、中蓝=启明=其余 171 个 TAMP 投顾团队 broker）。虚线为盈米柜台清算口径的投顾组合保有（stat 表 JOIN portfolio_type='P'），只覆盖走盈米柜台的部分——蜂鸟机构直连（约 1970 亿）与启明转托管的 TAMP 服务规模不在柜台口径内，所以柜台投顾（公司 532 亿）远小于公司全口径 AUM，两组线不可直接相除。灰色为且慢柜台口径构成序列（保有 / 自助 / 组合，stat 表），默认关闭；悬停气泡附且慢自助占比。2026-08 取 8-21（月未完）；启明 2021-11~12 回落为真实业务波动（两口径同趋势），2023-12 起新一批投顾团队接入放量。
回溯说明：全口径 AUM 已回溯至 combine 表最早数据日 2015-09-28（公司成立初期）——公司合计从 2015-12 的 0.01 亿起步，2016-12 = 9.96 亿、2018-12 = 173 亿、2020-12 = 650 亿，至 2026-08 = 2757 亿。由于跨度约 7 万倍，线性刻度下 2019 年前几乎贴零，点「对数刻度」可看清早期增长；2018 年以前的分 BU（broker）归属与现行业务语义不完全一致（如 2017 年「启明」已有十几亿，早于 TAMP 业务成立），早期公司合计可信、分 BU 仅作趋势参考。柜台口径（虚线）与且慢柜台构成仍自 2021-07 起（asset4 stat 体系建立时间）。

口径与来源说明
全口径 AUM（实线，2015-09 起，月度）
dwd_app_service_account_profit_combine ROOT 层 SUM(total_asset)，排 1002 通道户；该表最早数据日为 2015-09-28（实测 MIN(cal_date)，公司成立初期），2015-09~2016-02 实质为空盘（账户数个位数、规模＜0.1 亿）；total_asset 为综合资产（含在途订单、未结算资金、钱包/盈米宝）。维度按 broker 三分：蜂鸟 = '0000'（机构直连 ITS）、且慢 = '0008'、启明 = 其余 171 个 TAMP 投顾团队 broker；公司 = 全部之和。月末 = 每月最后交易日，2026-08 取 8-21。锚点与既有验证配方一致（2025-12 = 1952.59 / 2026-03 = 2271.61 / 2026-06 = 2753.90 亿）；回溯段衔接平滑（2021-06 = 805.70 → 2021-07 = 808.92 亿，同表同字段无口径断点）。回溯段共 70 个月由单日串行查询逐月取得（USE INDEX(idx_cal_date_saId)），无缺口。
柜台投顾规模（虚线，2021-07 起，月度）
stat_ca_asset_summary（盈米基金柜台 fundtxn 清算口径）JOIN portfolio_info（portfolio_type='P'，942 个投顾组合）月末保有。柜台口径只覆盖走盈米柜台清算的部分：蜂鸟机构直连全量（约 1970 亿）与启明转托管的 TAMP 服务规模、在途/未结算资金均不在其中——公司柜台口径保有仅 608 亿 vs 全口径 2757 亿，两口径不可混用。
且慢柜台构成：保有 / 自助基金 / 基金组合（灰色开关，2021-07 起，月度）
stat 表 broker='0008'：且慢柜台保有 363.71 亿（约为且慢全口径 408.41 亿的 89%，差额为在途/钱包）；按 po_code 分自助基金（FUND / QS_FUND）与基金组合（ZH* / SI* / LONG_WIN* 等）。悬停气泡内附自助占比。
投顾签约人数（2020-06 起，季度）
季度末时点有效签约（COUNT DISTINCT account3_id），老协议 ic_protocol_record ∪ 新协议 sign_record 两表 UNION 去重，broker=0008。
有交易用户数（2016-06 起，月度）
qm_meta.trade_detail 按月 COUNT DISTINCT user_id，canceled=0 且 po_code≠'WALLET'（仅基金申赎，排盈米宝）。
有资产 / 在管用户数（2023-06 起，半年度）
dwd_app_service_account_profit_combine ROOT 层去重，broker=0008，排 1002 通道户；有资产 = total_asset＞0，在管 = total_asset＞100（在管门槛）。2025-12 在管 290,782 与既有校验值差 0.03%。
