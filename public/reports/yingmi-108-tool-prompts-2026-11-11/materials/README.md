# 模拟案例素材库使用说明

> 全部为模拟案例／教学测试或空白准备单；非真实客户、交易、工具结果或投资建议。

这套素材将输入信息与计算结果分开。所有账户金额、持仓权重、交易、家庭情况和目标均为人为设定；产品代码只作为查询对象。私募准备单不含可执行标的，不能用虚构产品补位。

## 使用方法

1. 按工具选择素材；附件题附对应文件，纯文本工具可复制已给定信息。
2. JSON中request才是接口请求参数，外层是模拟标签/说明；调用按实时Schema转换，案例ID不能代替服务端ID。
3. CSV使用UTF-8 BOM，基金代码以字符串导入，权重通常用0—1小数；可视化素材中的饼图值另用百分数并注明单位。
4. 返回数据要记录实际时点、字段与缺失项；不将样本假设当查询结果。

## 一致性与口径

- M02市值100万元、权重100%、成本99.6万元；账面差额4000元仅为输入算术，不是真实基金业绩。
- M03目标权重100%；M04各调仓日全量权重100%；M05基准权重100%。M04独立回测样本不声称自然生成M02快照。
- M06独立交易算术：(61000−11500−300)/12500=3.936元/份；不是净值、真实分红或真实成交记录。
- M08/M18资产530万元、负债120万元、净资产410万元；可立即用于普通长期组合的资金100万元。
- M09/M17常规月收入4.6万元、常规月全部支出2.5万元；含奖金及旅行的年收入61.2万元、支出32.4万元、结余28.8万元。
- M19“月必要性现金流出”为1.9万元，按官网公式只含日常、缴费、通勤、各项贷款和保障型保费；与2.5万元常规全部支出不同。准备值需真实调用复核。
- M10教育月投6000+退休月投10000=16000元，不超过常规月结余21000元；专用本金不重复分配。
- M20是独立CF01现金流演示，不等同F01的完整预测；金额频率和年龄端点需按服务端核实，不冒充已验证结果。
- M27相关矩阵由人为设置，仅供作图；M30为待补信息表，不能直接执行真实私募查询。
