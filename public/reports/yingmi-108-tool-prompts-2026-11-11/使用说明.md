# 使用说明

1. 打开index.html，搜索能力并展开三问。HTML离线可读，无需加载第三方脚本。
2. 需要附件时，先把对应materials文件添加到对话，再复制完整提问。文件名不会自动上传文件。
3. 账户分析需本人授权；策略、方案及私募标识必须由真实前序查询产生。模拟案例ID不能传为服务端标识。
4. Excel和CSV每行一条问题，包含准备信息、附件、前提、预期交付、验收及可填写的实测记录。
5. 本资料是提问设计与素材库，未宣称324问全部在豆包工作、WorkBuddy和千问办公逐题运行成功。

范围：92 MCP + 10 Skills + 6 Agent = 108项；每项3问=324问。官网实时核对日期2026-11-11。
