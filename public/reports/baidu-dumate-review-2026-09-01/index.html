产品定位

百度搭子（DuMate）是百度 2026 年 3 月推出的桌面级 AI 办公智能体，覆盖 Windows / macOS / iOS / Android / Web。与对话式助手的区别在于它直接在本机执行：文件整理、多源数据分析、网页操作、生成 PPT/报告、定时自动化，官方口径是「从理解到执行的闭环交付」。登录强制百度或百度智能云账号（支持扫码、短信、微信/QQ/微博、企业子用户），无游客模式。

实测用例：金价周报复合任务

测试指令是一个刻意复合的任务：「每周三早 8 点搜集过去三个月国际金价走势（伦敦金+沪金，日/周/月涨跌、成交量、支撑压力位），分析美联储/美元指数/通胀/地缘因素，给出投资建议与风险等级并标注来源；现在先把今天的发我」——同时考察即时交付与定时自动化。

  • +0:00识别为复合任务，调用 Requirement Analysis 子智能体拆解交付要求与验收标准
  • +1 min建立 5 步任务清单，自动加载官方「金融投资套件」，执行 market-diagnostics 技能
  • +2–8 min12 次百度搜索，按维度分查：伦敦金/沪金行情、FOMC 决议、DXY、CPI/PCE、地缘冲突、ETF 资金流
  • +8 min中途自动做了一次上下文压缩（context compaction），长任务不断线
  • +9 min写出 15 KB Markdown 报告，按套件内图表模板库渲染为 34 KB HTML（8 个 ECharts 图表）
  • +12 mindeliverable-verify 流水线 headless 渲染自检（空图表/断图/文本截断/布局塌陷），23.7 秒
  • +13 min报告交付 + 每周三 8 点定时任务注册完成，5/5 子任务 completed

产物验收

报告六章结构完整：深度结论、双市场走势（含支撑压力位表）、四因素分析（FOMC 投票比、DXY、CPI/PCE、地缘事件表）、ETF 资金流向、三情景概率化研判与条件式操作建议、来源汇总 12 项 + 免责声明。事实抽查通过：报告称 8 月 29 日伦敦金收报 4453.67 美元、因沃什 Jackson Hole 鹰派讲话大跌，与腾讯新闻、新浪财经当日报道完全一致。

值得注意的细节：投资建议全部写成「条件触发式」（若跌破 4400 且加息概率超 60% 则……），不给确定性指令，并附免责声明——合规意识比多数同类产品到位。

架构拆解

逐层看，DuMate 是「国际开源智能体框架 + 百度模型生态」的组合，工程投入相当扎实：

  • dumate-opencode执行引擎是开源 opencode 的深度定制版，内部结构完全是 OpenClaw 风格：SOUL.md / AGENTS.md / MEMORY.md / USER.md，技能用与 Anthropic Skills 一致的 SKILL.md 规范
  • dumate-router模型路由层。实测主力模型是 GLM-5（智谱，经千帆个人配额调用 130 次），辅以 dm-auto-model 自动路由、qwen3.5-35b 轻量任务、dumate-image2.1 图像——并非文心独占
  • lightsandbox + vmmgr本地沙箱：570 MB 运行时 + 1.7 GB Linux 虚拟机镜像，Python 依赖走清华 PyPI 镜像按需安装，任务代码与主机隔离
  • deliverable-verify交付前质检流水线：headless 渲染 HTML 产物，审计空图表、断图、横向溢出、占位符残留、布局塌陷后才交付
  • skill_security_task技能安全机制：每个技能文件记录哈希并过安全扫描裁决（trusted source 可跳过）
  • 网络面本地各服务（router/main-server/opencode/浏览器扩展中继）全部只监听 127.0.0.1；外联仅百度系域名。「本地运行、数据不外流」的宣传与实测网络行为相符——但搜索与模型推理仍在云端

商业化

免费版每日赠 1000 积分、不跨日累计。实测一个复合任务就触发「积分即将用完」提示，随即弹出 Pro 升级入口（首月 ¥9.9）。也就是说免费版的真实容量约为「每天一件复杂任务」或几件轻任务，重度办公场景实质是付费产品。另有「充能计划」做增长（赚积分领电脑）。

优点与不足

做得好

  • 复合任务端到端闭环：拆解→执行→质检→交付→定时，全程免干预
  • 过程透明：每一步搜索词、读的文件、子任务都可展开查看
  • 交付前自动质检（dv-verify）是同类罕见的工程亮点
  • 产物合规意识好：条件式建议 + 来源标注 + 免责声明
  • 本地服务只监听回环地址，文件操作逐次授权
  • 套件/技能/自动化/文件库的产品化组织清晰，上手门槛低

短板

  • 免费积分约等于每天一个复杂任务，试用邀请式定价
  • 安装+数据 3.4 GB、内存 1.5 GB，是重型客户端
  • macOS 仅支持 M 系列芯片，Intel Mac 无缘
  • 定时任务依赖应用/云端在线，本地未注册系统级调度（周三 8 点关机是否补跑待验证）
  • 报告 HTML 引用公网 CDN 的 ECharts，离线打开图表会失效
  • 行情数据来自百度搜索转述而非行情 API，精度依赖新闻源（本次抽查无误）
