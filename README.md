# Clair's Studio

个人 AI 输入入口与生产成果库。

## 能力

- 页面仅保留一个统一输入框，支持输入框粘贴、页面直接 ⌘V 和拖入文件
- 统一输入使用 `Set an idea in motion`，操作按钮统一为 `Attach / Save / Decide / Review`
- 不保留本地处理队列；`Decide / Review` 自动匹配 Skill 并即时复制任务 brief
- `Save` 会自动识别标题、主题、工作类型和标签，并直接进入成果库
- 手动新增报告；同源公开页面自动识别标题，其他网址可手动填写且不会发送给第三方元数据服务
- 按产品、AI、投研、知识治理与经营主题归档
- 每份生产报告提供真实首屏预览，受限报告使用权限占位图
- 支持可逆归档：主目录一键归档、归档区搜索、恢复到原主题
- 永久删除只在归档区提供，并带二次确认
- 新增、改名和删除主题
- 拖拽报告换组；主题、类型、标签、时间四个维度的分组均可独立排序
- 分组标题无前置编号或类型图标，保持统一左对齐
- 点击顶部品牌或顶部空白区域可返回页面顶部；切换主视图不继承深层滚动位置
- 编辑标题和网址、删除
- 生产报告在当前页面内打开，并提供“返回清单”
- 阅读页可下载单文件 HTML 档案：样式、脚本、图片、视频与运行时读取的数据全部内嵌，断网或转发出去也能完整打开；抓取过程带进度与取消，抓不到的资源保留原始链接
- 需组织或账号登录的报告进入登录接力页，由用户在顶层新窗口手动完成验证，避免 iframe 空白
- 主题导航支持快速定位，搜索结果只保留命中的主题
- 内置 108 个经去重和生产可访问性核验的产出入口
- 列表隐藏报告地址、日期与低价值操作信息
- 兼容旧版浏览器数据：保留自定义分组、标题、置顶和手动新增条目
- 数据自动保存在当前浏览器

## 关键任务 Skill

五个 Skill 都包含输出契约、成功/失败路径测试和可分发 `.skill` 包。进化遵循：

`人工差异 → 优化候选 → 回归测试 → 人工批准 → 新版本`

## 本次目录口径

- 数据截止：2026-07-31
- 合并来源：且慢产品研究页面库、最近一个月 Codex 任务生产发布记录
- 去重规则：同 URL 只保留一次；同一产物的旧版、桌面保存副本和已被新版替代的页面不重复收录
- 排除项：失效生产页、仅本地草稿、失败任务和未完成发布

## 说明

Clair's Studio 与仓库内成果报告均为公开直达页面，不设置工作台口令或报告访问密码。第三方协作文档仍遵循原平台的组织帐号与权限规则。报告清单使用 `localStorage` 保存，不会自动同步到其他设备。

本地成果会在当前浏览器保存文字、链接、文件名与可读取的文本摘要，不会把原文件上传到服务器；协作文档仍以原平台链接为准。
