二、市场温度计的精确数学公式

2.1 温度公式 已确认

证据：commons-processor/pybin3/ProcessMarketTemperature.py L114-121、L130-153（作者 lilongbo，2022-05-30）

# 每个交易日、每个指数：
pe_rank    = pe_median  在历史窗口内的百分位排名   (pandas rank method='min', pct=True)
pb_rank    = pb_median  在历史窗口内的百分位排名   (同上)
risk_rank  = risk_premium_rate 在历史窗口内的百分位排名 (同上)

temperature = (pe_rank + pb_rank + risk_rank) × 100 / 3
最终落库 = round(temperature, 2)          # 保留 2 位小数，范围 0~100
  • 权重：PE 分位、PB 分位、风险溢价分位 等权 1/3，无任何其他加权。
  • 百分位定义（pandas 语义，推断自 pandas 官方 rank 语义，未环境实测）：min_rank / 有效样本数。并列值取相同最小名次；NaN 被排除在分母外。
  • 方向语义：PE 越高温度越高（越热）；PB 同理；风险溢价率越高温度越低——注意风险溢价 risk_premium_rate = 十年国债收益率/100 − 1/PE 本身是“债券收益 − 股票盈利收益率”，值越大代表股票越不划算 → 应该越冷。但代码直接对它 rank 后正向计入温度——即风险溢价率越高 → risk_rank 越大 → 温度越高。这是一个方向值得注意的实现细节（见 §2.5）。

2.4 去极值 / 缺失值 / 负 PE 边界处理

边界场景处理方式证据等级
去极值（winsorize）没有任何去极值处理。直接用原始 pe_median/pb_median/risk_premium_rate 做百分位排名。由于温度本质是序数统计（rank）而非均值，极值天然只占一个名次、不放大影响——这是设计上“天然抗极值”的选择。已确认（全代码无 clip/quantile 截断）
负 PE / 负 PB照常参与排名。个股层面取数时 PE/PB 只要非 null 即纳入中位数聚合；指数层 pe_median 若为负（熊市亏损股多时可能），rank 按数值大小正常排序（负值 = 最低名次 = 最低温度）。没有“剔除负 PE”逻辑。已确认（L94-95 取数 + rank 逻辑）
缺失值（某日无数据）①个股层：PE/PB 各自 is not null 独立过滤；②指数层：当日若因内 merge 缺失则该日直接不产出 base 行（内连接 txn_day × pbpe × 国债收益率三者都齐才写库）→ 温度计算跳过该日；③API 层：查不到温度时 pmdj 返回 temperature=0, rating='UNKNOWN', ratingText='暂无数据' 的降级项（不抛错）。已确认
并列值（如 PE 相同）rank(method='min')：并列取最小名次，pct 分母为非 NaN 样本总数。推断（pandas 语义）
风险溢价为 NaN（pe_median=0？）1/pe 若 pe=0 会产生 inf，代码未防护——但聚源 PE 为 0 的指数日基本不存在（中位数层面），实际风险极低。推断（潜在边界，未见实际触发证据）

2.5 需要产品侧留意的一个口径细节 推断（方向语义值得复核）

常规“股权风险溢价 ERP”口径：ERP = 股票盈利收益率(1/PE) − 无风险利率(10Y国债)，ERP 越高股票越便宜（越冷）。

而本实现的 risk_premium_rate = 10Y国债收益率 − 1/PE，是上者的相反数（即“债券相对股票的溢价”）。按通常理解，该值越大 → 债券越有吸引力 → 市场应越冷；但代码把它正向 rank 进温度（值越大温度越高）。

两种可能：①产品设计有意如此（把“债券溢价高”视为“之前股票涨太多/利率升”的热度信号）；②方向笔误但已按此口径跑了 4 年，历史分位机制会自我消化（分位对称，只影响“温度读数方向”这一维度的含义）。建议与数据组 lilongbo/产品确认原意——若确认为笔误，对“温度计”三因子中 1/3 权重的方向有实质影响。

七、可复现口径总结（一段话版）

市场温度（0-100，近10年窗口，五档）：取该指数（中证全A/沪深300/中证500）当日成分股（聚源月度快照，中证全指 2011-08 前用最早快照）的 PE(TTM) 中位数与 PB(LF) 中位数，以及风险溢价率 = 10Y 国债到期收益率(%) − 100/PE(%)（即 1/PE 换算为百分数的盈利收益率）；三者各自在“过去 10 年交易日（含当日）”内做百分位排名（pandas rank min/pct），温度 = 三分位平均 × 100，保留 2 位。≤20 低估 / ≤40 较低估 / ≤60 合理 / ≤80 较高估 / >80 高估。

行情解读：五指数（沪深300/创业板/道指/纳指/伦敦金）当日收盘价与日涨跌幅直接取自 FDP 数仓 dwd_index_price_daily（盈米零计算）；涨跌幅超各自阈值（2/3/2/3/1.5%）且按收盘价落入三档点位区间的，命中静态文案矩阵生成解读，否则只给行情数字。
