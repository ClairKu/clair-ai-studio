项目名称：且慢账户定期检视与目标续管 Agent
提报状态：建议稿，未立项；日期：2026-10-20
实施建议：第二批 / 复用底座后 8–10 周

业务痛点
账户复盘往往耗在取数、对账、做报告，报告交付后是否解释清楚、是否形成后续动作、目标是否变化缺少持续管理。

项目目标
按约定周期完成账户事实核验、顾问签发、客户沟通和后续问题跟踪，使报告成为持续服务中的交付物。

首期范围
首期只做平台内已授权账户的季度检视；家庭外部资产和目标变化仅采集客户确认信息。不自动调整配置与交易，不将市场波动直接等同于目标失败。

触发条件
约定季度到期；目标或用钱时间由客户确认变更；权威规则识别的资产／风险偏离。阈值由投研与业务共同批准。

端到端流程
检查检视到期 → 汇总持仓现金流与历史方案 → 口径对账 → 计算收益／风险和目标差距 → 识别需补证问题 → 生成复盘草稿 → 顾问复核签发 → 沟通与理解反馈 → 创建后续实施／资料任务 → 核验或延后 → 进入下一周期。

AI承担
组织取数和补证、调度已验证计算工具、解释差异、草拟复盘、持续追踪后续任务与版本变化。

人工责任
顾问确认诊断和方案建议并签发；客户确认目标和下一步；涉及个性化方案及执行仍走正式审批和确认。

数据与系统依赖
账户与交易事实、收益口径与校验器、历史方案版本、客户确认目标、报告签发／送达、任务和问题结果。账户／组合／底层基金不可重复加总。

验收标准（建议值）
建议：按期有效检视闭环率≥80%；顾问准备工时下降≥40%；数值与权威系统一致率100%（批准容差内）；所有签发结论可定位数据时间与计算版本。未对账成功则阻断签发。

交付物
季度检视SOP、指标字典与对账器、版本化报告、审核交付记录、目标变化与后续任务台账。

责任组织
业务负责人：顾问服务；投研负责诊断与计算口径；产品编排流程；账户／交易数据团队提供事实与对账。

L3成立依据
从定时检视一直推进到客户反馈和后续动作核验，可跨周期恢复；仅自动生成报告不足以成项。

资源与验收补充：与总材料的共享底座、90天阶段门、分组试验及权限表配套使用。全部目标为待基线验证的建议，不是已实现收益。公司L3评审口径、业务负责人、接口权限和预算须评审确认。
