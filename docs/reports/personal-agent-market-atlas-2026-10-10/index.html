01
EXECUTIVE THESIS

先把“AI 助手”这个词拆掉

市场把不同物种都叫 Agent。真正有意义的分界不是能不能对话，而是它拥有多少持续代理权，以及出错时谁能阻止、解释和追责。

判断 01

模型正在变成零件

真正的产品是记忆、身份、连接器、浏览器 / 手机、后台运行、审批和审计拼成的执行系统。换一个更强模型，不会自动补齐这些。

判断 02

便利与主权同向增长

Agent 越懂你、越能行动，就越需要你的邮件、关系、位置、付款和账号。功能价值与潜在伤害使用的是同一组权限。

判断 03

“主动”迟早会商业化

当 Agent 能替用户决定下一步，推荐位不再只是广告位，而是行为分配权。Instinct 的主动商品推荐已经暴露这种利益冲突。

判断 04

大厂赢分发，小厂赢代办

Meta、Google、Apple、Amazon、Microsoft、中国超级 App 拥有入口和账户图谱；创业公司靠电话、旅行、购物和人工兜底跑得更深。

判断 05

本地化不是免费午餐

Underdog、OpenClaw、Hermes 把数据主权还给用户，却把部署、更新、密钥、隔离和故障责任也一并还给用户。

判断 06

责任条款是隐藏的产品页

首页展示“替你完成”，条款往往写“你承担后果”。判断一个 Agent，不只看演示，还要看删除、训练、交易授权和赔偿边界。

02
DELEGATION STACK

Personal Agent 是七层委托栈

少一层，产品就会退化：没有长期记忆只是会话；没有行动载体只是建议；没有审批与审计，则是把不可控包装成自主。

入口

批判性检查：多数发布会展示前五层，把最后两层放进隐私政策和服务条款。恰恰是最后两层，决定它能否从“惊艳演示”变成可信基础设施。
03
MUSE × INSTINCT

两个极端：系统工程 vs. 代办服务

Muse 的野心是把一个安全执行环境铺到个人生活；Instinct 的野心是让一个像人的助理接管现实世界杂务。前者更重控制面，后者更重结果感。

META · PERSONAL AI AGENT

Muse

“一个持续存在的你之外的大脑”

围绕目标、背景任务、应用连接和云端浏览器工作；用 Secure VM、Sentinel、凭证代理、网络出口控制和确定性审批构建安全边界。

工作形态主对话 + 侧线任务 + 长期目标
行动载体每位用户隔离的 Muse Secure VM
安全设计凭证不直接暴露给模型；受污染数据限制外发

真正强在哪里

工程优势不是把浏览器自动化贴在聊天框上，而是从凭证、网络、运行单元到审计重新设计控制面。
分发优势Meta 的关系网络、广告生态和消费者触达，为长期个人画像提供天然燃料。

Instinct

“发短信或打电话，就像叫一个真人助理”

用电话、邮件、浏览器和支付完成账单、礼物、采购、医生预约、旅行等现实任务；产品感觉最接近传统私人助理。

工作形态文字 / 电话下达，异步代办

真正强在哪里

现实执行把“我建议你打电话”变成真正替你打电话、等待、谈条件和下单。
低学习成本不要求用户理解工作流或插件；一句自然语言任务即可启动。

必须读条款才看见的风险

数据边界隐私政策覆盖消息、邮件、音频、敏感信息、支付、位置及使用行为，并允许与第三方模型提供商共享。

责任转移用户授权 Instinct 代表自己达成有约束力的交易，并承担财务、法律和声誉后果；已有误取消航班损失报道。

06
WHERE MOATS REALLY ARE

护城河不在“更会聊天”

市场最终不会由一个总榜单决定，而会由三种稀缺资产形成不同赢家。

①

分发与上下文

Meta、Google、Apple、Amazon、Microsoft、Alibaba、Tencent 已经握有入口、账号、关系或交易图谱。

  • 优势：无需说服用户迁移全部生活
  • 风险：平台商业目标可能渗入代理决策
②

执行与运营

Instinct、Wajo、Airtap、Tab、Hark 用电话、云手机、人工兜底和流程运营把任务做完。

  • 优势：用户直接感到“省事”
  • 风险：单位经济、事故与赔付压力
③

控制与所有权

Underdog、OpenClaw、Hermes 选择端侧或自托管，让用户掌握运行环境、模型和数据。

  • 优势：可迁移、可审计、弱平台依赖
  • 风险：复杂度和运维责任回到用户
07
CRITICAL THINKING

八个容易被产品演示掩盖的问题

批判性思考不是否定新技术，而是追问被省略的前提、激励、边界和失败成本。

1

能力剧场

一次成功演示不等于可重复交付。应追问真实完成率、人工介入率、平均耗时和失败后的恢复成本。

2

授权剧场

弹一次“允许”不代表知情同意。真正授权必须有对象、范围、时限、额度、撤销和后果说明。

3

记忆陷阱

长期记忆既是体验资产，也是持续累积的攻击面。断开连接、删除原邮件和删除 Agent 记忆是三件不同的事。

4

责任套利

产品用“替你完成”获客，却用条款把财务、法律和声誉后果归回用户。服务边界与赔付机制必须前置。

5

主动性变广告库存

当 Agent 主动建议消费，用户无法只看“推荐是否相关”，还必须知道是否付费、平台抽成、目标函数是谁的。

6

反自动化现实

验证码、动态页面、风控和服务商条款并不会因“Agent”消失。绕过限制可能带来封号、订单和合规风险。

7

云代理单位经济

一人一台云电脑、长时间推理、电话和人工兜底都很贵。免费 / 低价可能不可持续，或由交易佣金和广告补贴。

8

应用被中介化

Agent 截走发现、比较与下单入口后，商家可能失去用户关系；平台则获得前所未有的议价和排序权。

08
CHOOSING GUIDE

不是选最强，而是选匹配的责任边界

以下建议基于公开证据和产品形态，不是绝对排名。任何涉及金融、医疗、法律或不可逆交易的任务都应保留人工确认。

想要完整消费级体验Muse安全控制面和长期协作更完整，但应关闭不必要训练、限制连接器并定期清理。
想要强电话 / 旅行代办Instinct / Wajo结果感强；只用专用邮箱、虚拟卡和明确上限。
想交付知识工作成品Claude Cowork / dots / Manus / Grok Bot按文件、工具生态和本机访问需求选择。
主要生活在中国生态千问交易履约闭环领先；腾讯 / 百度更偏办公与通用生产力。

技术团队要自主可控OpenClaw / Hermes提供可修改路线，但安全运维不能外包给“开源”二字。

六步安全试用协议

01新建专用邮箱 / 账号，不接主身份
02先给只读权限，观察日志和记忆
03支付使用虚拟卡、低额度和单次授权
04删除、取消、发送、签约必须逐次确认
05每周审计连接器、已存记忆和失败任务
06退出时同时撤权、删索引、删记忆并留存凭证
FINAL VERDICT

谁最聪明，不是最重要的问题。

最重要的是：它代表谁的利益、拥有多大权限、如何被叫停，以及出错后谁付钱。

Muse 证明 Personal Agent 正在走向系统级安全工程；Instinct 证明用户愿意为真实代办让渡极大权限。它们共同宣告聊天框时代的上半场结束，也共同暴露下一阶段的核心矛盾：越像“第二个你”，越不能只靠信任品牌。

对产品团队的四条硬建议

  1. 不要从“万能助手”立项，从高频、可审计、可止损的闭环任务立项。
  2. 把授权、日志、撤销、赔付做成产品能力，而不是法务附件。
  3. 每个主动建议都显示触发原因、商业关系和目标函数。
  4. 核心指标用成功闭环率、首次正确率、越权率、恢复时长和净节省，不用会话量制造繁荣。
