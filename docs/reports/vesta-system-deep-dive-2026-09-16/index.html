Product positioning

产品定位
不是“数据查询网站”

官方年度汇报把 VESTA 定义为“盈米投研核心底座、投研工业化引擎”。结合当前产品与 MCP 实测，更准确的说法是：它把研究数据、研究框架、量化算法和生产工具做成可复用能力，再服务投资经理、投顾与机构客户。

核心定义

面向买方投研与投顾生产的
“研究操作系统 + 能力工厂”

输入是标准化数据与研究材料，中间是对象、模型、算法和工作流，输出是信号、观点、基金池、组合、报告、API/MCP 与机构 SaaS。它的价值不在单个页面，而在“一份研究成果能否被多渠道重复消费”。

边界要说清

负责研究生产、模型计算、产品评价、组合构建与分析、研究成果标准化输出。
连接PMS、启明、且慢、蜂鸟、机构 SaaS、API/MCP、AI Agent 与报告渠道。
不替代客户适当性、合同签署、账户交易、支付、最终下单确认和业务审计。
北极星缩短“数据 → 研究判断 → 可审核成果 → 多渠道使用”的周期，并让结论可追溯。
Product framework

一套底座
两座工厂、多个出口

年度汇报的原始产品框架可还原成四层：基础数据库、研究工厂、算法工厂、投研平台。它们不是简单上下游，而是由数据工程师、研究员、金融工程师共同生产，再供投资经理与投顾消费。

2026 年度产品路线图（原规划）

组合引擎 50%、公募分析 80%、私募分析 35%、投资池 60%、风险模块 55%；先把核心链路做“可用”。

2026 Q3

组合引擎 90%、公募分析 100%、私募分析 55%、投资池 80%、风险 65%、投研接口 15%。

2026 Q4

规划缺口：原路线图把大量人月放在功能完成度，却没有同步给出活跃用户、研究交付周期、复用率、审核通过率、接口 SLA 等结果指标。建议从“功能百分比”升级为“岗位任务闭环 + 质量与采用率”双重验收。

各自负责什么

把边界画清楚，才能避免“研究系统变交易系统”或“开放平台重复建设投研逻辑”。下图按上游输入、VESTA 核心、下游消费与能力分发分层；CORAL 的精确迁移范围仍待项目档案复核。

CORAL（历史系统）

Dify / AI 工作流

已用于经理总结、简报等生成流程；它是编排与生成工具，不是投研数据与算法的所有者。

RESEARCH CORE

VESTA

研究数据对象化、算法模型化、研究过程产品化、成果能力化

研究工厂算法工厂产品与组合信号与观点风险与归因报告与接口

PMS

承接产品/组合运营、账户与交易执行。VESTA 输出研究结论和组合方案，PMS 返回持仓、调仓与执行反馈。

启明 / 且慢 / 蜂鸟 / 私财

API / MCP

把原子数据、指标、信号、基金与组合分析标准化输出；123 项在线工具体现了 2026-09-20 的当前能力面。

OAP / STARGATE / Agent

负责能力注册、鉴权、分发、计量与工作流编排；投研公式、版本和数据责任仍应归 VESTA 治理。

数据与材料 → VESTA 研究生产 → PMS/业务平台落地 ｜ VESTA 能力 → API/MCP → 开放平台与 Agent 分发

Product diagnosis

真正的问题
不在“功能不够多”

VESTA 的功能密度已经很高。当前最需要解决的是：用户如何从对象进入任务、如何理解口径、如何把结果写回业务，以及平台如何证明每个结论可复核。

1. 页面多，任务链仍断

基金、经理、组合、信号、研报都很强，但“选对象 → 诊断 → 形成观点 → 生成报告 → 审核 → 输出”仍需要用户跨页拼装。

2. Chat 共屏但不共上下文

历史实测中 Chat 无法自动读取当前经理页；长任务还出现网络中断。它更像通用问答，不像对象页 Copilot。

3. 口径治理追不上能力增长

250/252、自然日/交易日、总资产/净资产、报告期/估算、排序分位/参数分位等并存，缺少统一口径护栏。

4. API 成功不等于业务可信

存在静默空值、Mock、隐藏必填、枚举不全、错误码不一致；“HTTP 200”远不足以作为能力验收。

5. “高级权限”不是可解释权限

本轮证明组合对象可读、云盘仍拒绝、网页会话仍失效。RBAC、机构、对象、空间与动作必须汇总成可查询的权限清单，而不是让用户和 Agent 逐接口试错。

6. 产品价值未被包装成岗位成果

研究员要的是报告、观点和跟踪清单；投顾要的是可解释结论；机构要的是稳定接口和 SLA。页面功能还没有完全转成岗位结果。

Action plan

下一步优先级
不是再加菜单

建议沿“任务闭环、口径契约、AI 共上下文、能力治理”四条主线收敛，先让已有能力变得可用、可解释、可复用。

建立对象页 Copilot

基金/经理/组合/信号页自动注入对象、选中表格、筛选条件、图表口径与数据截止时间，提供“解读本页、生成报告、生成话术、找异常”四个动作。

每个指标拥有公式、单位、方向、年化基数、分母、频率、来源、版本、缺失处理与示例；页面、API、MCP 共用一份 SSOT。
