PERSONAL AGENT · BOARD DECISION BRIEF · 2026.10.10

入口会被重排，信任与执行不会。

Personal Agent 正从“回答问题”进入“持续理解个人、主动发现任务、跨应用执行并对结果负责”的阶段。盈米不应复制一个万能助手，而应成为所有 Personal Agent 都绕不开的受监管个人金融任务操作系统。

董事会结论先行7 项一手外部证据金融合规边界90 天行动计划公开安全版
ONE-LINE STRATEGY

通用 Agent 抢入口，盈米守住“金融身份、专业判断、合规责任、资金执行”四个不可外包的控制点。

战略不是“再加一个 AI 入口”，而是把现有投研、账户、顾问、运营、OAP/MCP 组织成可被自己和外部 Agent 安全调用的任务闭环。

做什么一核两面三闭环：金融智能核心；客户面 + 顾问面；感知、授权、执行验证。
先做谁优先顾问 Agent 和存量客户陪伴，再扩到第三方 Personal Agent 生态。
不做什么不造通用超级 App，不让第三方入口直接完成投顾互动、适当性或交易。

03
WHERE TO PLAY

不要在对手的主场，打最贵的一仗

模型公司、操作系统和超级平台天然占据入口与通用上下文；盈米真正稀缺的是受监管金融身份、适当性、账户与持仓、策略方法、顾问责任和交易闭环。

STRATEGIC THESIS

赢法不是拥有最大的 Agent，而是拥有最可信的金融“最后一公里”。

通用 Agent 可以理解“我想为孩子准备教育金”，但它不应替代持牌机构完成个性化投顾、适当性判断、产品销售或资金动作。

对外成为各类 Personal Agent 的“金融能力与可信执行层”；对内成为客户、顾问、投研、运营共用的任务操作系统。
必须自己掌握金融身份与授权账户、持仓与目标状态策略方法与证据链顾问审批与交易执行
不值得重造通用模型与搜索系统级语音入口通用办公和网页操作全场景个人记忆

05
BUSINESS PATHS

三条增长路径，共用一套底层

Personal Agent 的商业价值不应只写成“提升体验”，而要落到客户留存与资产沉淀、顾问产能与服务质量、机构生态收入三个结果池。

B2C · 客户

个人财富管家

围绕目标、现金流、持仓和市场事件持续在场，把“行情触发焦虑”改造成“基于账户事实的下一步行动”。

  • 主动发现目标偏离与现金流风险
  • 解释持仓受何影响、是否需要处理
  • 把高风险或复杂问题无损交给顾问
目标留存任务闭环率顾问接管率资产沉淀
B2A · 顾问

顾问任务 Agent

每天自动形成客户优先级、证据包和服务草稿；顾问把时间投入判断、沟通和关系，而不是搜集与搬运。

  • 客户事件 → 待办 → 建议 → 审批
  • 统一适当性、产品和市场证据
  • 服务结果反写客户任务状态
首次通过率单客服务时长有效触达合规退回率
B2B2C · 生态

可信金融能力层

把查、诊、规、伴、办拆成受治理能力，通过 OAP/MCP/Skills 被机构和通用 Agent 调用；高风险环节回到持牌自营闭环。

  • 标准能力 + 场景模板 + 证据回执
  • 按机构身份、用途与客户授权发权
  • 从接口调用升级为任务结果交付
激活机构闭环任务调用成功率生态收入

顾问任务 Agent

先从内部人机协同切入，风险最低、反馈最快，还能反向沉淀 C 端 Agent 的正确做法。

触发
市场/账户/生命周期事件
输出

验收
首次通过率、节省时长、合规退回、实际触达

目标与现金流管家

把养老、教育、应急与长期投资目标做成持续状态，而不是一次性测算页面。

触发
入金、支出、目标变化、偏离阈值
输出
差距解释、可选动作、用户确认、复盘
验收
目标更新、计划执行、留存与反悔率

持仓风险解释器

市场波动时主动回答“我的钱发生了什么”，而不是泛泛生成行情观点或追涨杀跌内容。

触发

输出

BOUNDARIES BEFORE AUTONOMY

L3 不是“全自动”，是“边界内主动”

金融场景真正的产品能力，不是减少确认按钮，而是精确知道什么可以自动、什么必须审批、什么绝不能做。

等级Agent 权限典型任务必要控制默认策略
A0公开信息生成解释术语、汇总公开资料、通用投教来源、时点、AI 标识可自动
A1个人数据只读查看本人账户、目标、任务与持仓事实明确授权、最小字段、可撤销用户主动触发
A2生成个性化方案草稿组合诊断、目标方案、客户沟通建议适当性校验、证据包、顾问审批人审后生效
A3推进高风险动作个性化投顾、营销触达、交易草稿、资金动作双重确认、自营渠道、日志、回退/补偿不得静默执行
禁止越权或不可解释收益承诺、代替适当性、跨客数据、无审批交易拦截、告警、人工接管零容忍
最容易被忽略的监管结论：《金融产品网络营销管理办法》已于 2026-09-30 实施。第三方互联网平台不得介入销售合同、资金划转、适当性测评等销售环节，也不得就金融产品与消费者进行互动咨询；购买与服务环节应跳转金融机构自营平台。算法营销还必须提供关闭个性化推荐的选项。D-008 查看原文

因此：千问、豆包、元宝、ChatGPT 等外部 Personal Agent 可以是发现、教育、授权和导流入口，但不能被设计成绕过持牌自营闭环的“隐形理财顾问”。具体产品方案仍需合规与法务逐案确认。

KEY FINDINGS

五个不可回避的结论

会议总结可以直接使用以下五条。

01

Personal Agent 已从功能竞争进入“代理权”竞争

常驻记忆、后台任务、应用连接和跨端执行已由多家头部平台正式发布，不再只是实验室概念。D-004D-005D-006D-007

02

通用入口会集中，垂直责任不会消失

金融产品的咨询、适当性、销售与资金动作仍要求持牌、自营、审批与回溯；这恰恰构成盈米的战略纵深。D-008

03

公司要建的不是“AI 小顾 4.0”，而是统一金融任务底座

客户、小顾、顾问、运营与外部生态若各自维护事实、权限和方法，将形成新的烟囱和合规风险。策略判断

04

顾问端应成为主动 Agent 的第一训练场

内部人机协同既能产出业务价值，也提供高质量反馈、审批和异常样本，风险显著低于直接开放 C 端自主执行。策略判断

05

90 天验收必须看任务和经营结果

闭环率、首次正确率、越权率、顾问接受率、客户留存与资产变化，比 DAU、会话数和 Agent 数量更接近真正价值。建议指标
