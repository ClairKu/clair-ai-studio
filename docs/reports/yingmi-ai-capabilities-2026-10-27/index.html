07 / OPEN COLLABORATION

从现有基础出发，选择接入方式

与机构共同确定场景、权限、数据范围和交付标准，再组合金融工具与智能体能力。[2][4]

PATH 01

AI 能力接入

适合已有AI平台或智能体框架的机构，将盈米金融能力接入现有技术体系。

接入形式：API / MCP · Skills
适配：基金分析、组合诊断、投顾报告
PATH 02

联合解决方案

结合阿里云运行底座与盈米金融服务引擎，搭建适配机构业务的智能体方案。

协作重点：运行环境 + 专业能力
适配：希望验证标准业务场景的机构
PATH 03

智能体场景共建

围绕明确的业务入口与服务目标，共建嵌入机构流程的场景智能体。

应用入口：App / H5 / 企业微信 / 工作台
适配：已有场景、客户关系与服务流程的机构
底层技术合作 · 阿里云

通用基础能力与点金核心引擎提供模型、运行时、记忆与沙箱等支撑；盈米提供金融MCP、Skills与Agents。[2]

生态触达 · 千问 / 百炼 / WorkBuddy

千问APP承载小顾智能体；百炼与千问办公接入金融工具和技能；WorkBuddy承载投研任务编排。不同入口承载不同能力。[3][5][8]

◉

数据与授权

明确客户授权、敏感数据范围与处理环境，按业务需要使用信息。

⌘

权限与操作

↗

◎

09 / PEOPLE & ORGANIZATION

让专家经验，成为组织可复用的能力

通过工具普及、技能平台和持续共创，连接业务与技术。人负责目标、规则与验收，AI辅助执行具体任务。[11][12]

01

业务定义场景与价值

从实际问题出发，明确输入、规则、目标与交付要求；把专家经验整理为可复用的知识和任务方法。

02

技术支撑接入与运行

建设模型、数据与工具平台，完成系统对接、运行环境、权限配置和必要验证，支持业务团队使用。

03

组织支持培养与迭代

通过AI分享、应用共创、编程工具和内部技能平台，持续沉淀实践；用结果检验任务与流程的改进。

识别场景→沉淀知识与规则→人机协同交付→验证与持续改进
