二、逐工具口径（实测）

1. get_cn_investment_signal_score（A股权益信号总闸）✅实测

  • 返回结构：score_data[] + wind_a_index_data[]（万得全A 881003.WI 收盘价）+ query_start/end_date + total_records。
  • 信号字段（全部 0/1 二值）：
    • position：最终信号，1=乐观、0=谨慎（与 VESTA 前端"中国A股信号"栏一致）。
    • position_long：长周期仓位（工具描述明确强调"不是多头"含义上的 long/short，是长/短周期）。
    • position_short：短周期仓位，1=过滤通过（不是看空）。
    • 子项因子得分（只解释当日因子，禁止用来自行合成 position）：position_1 估值、position_2 市场情绪、position_3 经济景气、position_4 货币流动性，各 0/1。
  • 合成线索（实测验证）：8-26→8-27 翻多当日，恰是 position_4（货币流动性）从 0→1，使 4 个子项达到 3/4，同日 position_long 0→1，position = position_short × position_long（backtest 工具文档明示该乘法）。推断 position_long 由 4 子项按某阈值（疑似 ≥3/4）触发，但阈值规则未在文档中给出，工具描述反而禁止自行合成——即官方口径为"黑盒，原样使用"。
  • 频率：日频（交易日），窗口 2026-08-20~09-02 返回 9 条，最新到 09-01（T-1）。
  • 时间戳：record_date（YYYY-MM-DD）。

3. get_cn_investment_signal_backtest ✅实测

  • 字段：benchmark_netvalue（买入持有万得全A，初始 1）、strategy_netvalue_long（只跟 position_long 调仓）、strategy_netvalue_short（只跟 position_short）、strategy_netvalue（综合，position = position_short × position_long）+ 三个仓位字段（0/1，空仓/满仓，无中间仓位）。
  • 实测样例(09-01)：benchmark 1.555 vs 综合策略 3.548 —— 净值起点日期未在返回中给出（疑点：无法据此换算年化超额）。
  • 无胜率/回撤/夏普等统计字段——回测"统计口径"只给净值曲线，胜率需调用方自算。
  • 有 update_time（实测 "2026-09-02 12:51:31"，日内更新）。

4. get_cn_investment_signal_china_style_score（风格轮动）✅实测

  • position_data[]：5 个 0/1 子得分：position_1 流动性偏好、position_2 资金偏好、position_3 景气扩散、position_4 估值、position_5 拥挤度；两个复合分：position_score_1 绝对收益得分(0-2)、position_score_2 相对收益得分(0-3)；三个仓位：position_dvd 红利低波、position_growth 成长、position_cash 现金（三者和=1）。
  • 实测(8-25~9-01 恒定)：子项 1,1,0,1,1 → score_1=2、score_2=2 → 红利 0.75 / 成长 0.25 / 现金 0。
  • 合成线索：score_1(0-2) + score_2(0-3) 两条打分线怎么由 5 个 position 映射、又怎么映射到 75/25 仓位，文档未给规则（疑点）。仓位是 0.25 步进的离散档位。
  • 附 dividend_index_data（红利低波指数）、growth_index_data（国证成长指数）价格序列。
  • backtest 姊妹工具（仅 schema）：strategy vs benchmark（红利50%+成长50%）vs 纯红利 vs 纯成长四条净值。

5. get_cn_investment_signal_china_style_factor ✅实测

  • 10 个指标：dividend_yield 股息率(%)、index_crowding 拥挤度因子(%，0-100)、m1/m2/m1_m2（月频，M1-M2 剪刀差=流动性偏好因子，宏观指标代码 1157/1158）、fund_raising_daily=fund_raising_daily1（基金日新增规模，亿元，同源双名，请求任一自动返回两个）、booming_industry_pct 景气扩散因子(%，0-100)、loan_rate、deposit_rate。
  • 实测确认：此处 dividend_yield≈4.32%（红利低波指数的股息率，与 signal_factor 里万得全A 的 1.33% 不同标的，同名不同口径，需注意）；index_crowding 55~66%；booming_industry_pct 仅 8-31 有值 31.03（月频，未铺日，返回 null）；m1_m2 近窗口全 null（月度数据未对齐交易日时直接 null，与文档"只返回宏观库有值日期"的说法不一致——实测是铺了日期但值为 null）。

6. get_grri_signal（GRRI 全球风险共振指数）✅实测

  • GRRI = Global Risk Resonance Index（工具文档给出全称），衡量全球多资产波动率+相关性的风险共振。
  • 字段：grri_value（字符串型数值！）、correlation_value（跨资产相关性）。日频，自然日连续（含周末 8-22/23/29/30 有值），最新到 09-02（T+0）。
  • 文档阈值：>3 极高风险、>2 高风险、>1 中等风险。实测值 -0.27~+0.17，correlation 0.205~0.214。
  • 疑点：grri_value 可为负 → 应是标准化(z-score)指标，阈值 1/2/3 即 1/2/3 个标准差；但"由哪些资产、多少个、什么窗口的波动率/相关性"构成完全未披露；数值以字符串返回（8 位小数）。

7. get_gold_signal_factor（黄金信号）✅实测

  • 只有 factor 工具，没有 score/backtest —— 黄金线只提供原料指标，无合成信号（疑点：VESTA 前端若展示"黄金信号"结论，其合成逻辑不在本 MCP 内）。
  • 14 个指标混用两种编码体系：数字宏观代码（2006 COMEX金、2189 美10Y实际利率、2190 央行净买入、2007 黄金ETF持仓、2191 美未偿公共债务、2086 美财政赤字、2193 美元外储占比、2192 地缘政治风险指数、2077 VIX、2056 金融压力指数）+ 字符串计算指标（net_long 非商业净多头、cpi_volatility 美CPI波动率）+ 行情代码（LBMAGOLDP.GI、AU9999.SGE）。
  • 返回结构与其他 factor 不同：{status, message, data:[{factorCode, dataList:[{recordDate, value}]}]}，value 为字符串，无 factor_name/unit 元数据（调用方需自备代码→名称映射）。
  • 实测频率：2006/2189 日频（交易日）；2192 地缘风险自然日连续；net_long 周频（窗口内仅 8-25 一条，对应 CFTC 周度持仓报告节奏）。请求的 cpi_volatility、2190 在近窗口无数据行（月频/低频，短窗口直接不返回该 factor 块）。

8. get_sectoral_signals（中观行业·横截面）✅实测

  • 无入参；返回 update_time（实测 2026-09-02 08:44:14，每日早晨批跑）+ 29 个中信一级行业（CI005001~CI005028 + CI005030 综合金融；无 CI005029，银行/非银单列，体系为中信 CITIC 一级行业指数，注意缺29号位）。
  • 每行业 10 个信号字段，取值不是统一 0/1：
    • sign_ecop 经济周期：实测 -1/0/1/2（电子、通信=2）→ 至少 -12 四档，可能 -22。
    • sign_curp 货币周期：实测 -2~2 五档全出现。
    • sign_tech 技术周期、sign_policy 政策周期：实测 -1/0/1。
    • sign_trd 景气水平、sign_lvl 景气趋势：实测 ±1 二值（两者实测 29 行业全部同号，疑似强相关或同源，且 digest 里 trd 标"景气水平"/lvl 标"景气趋势"与字段名直觉相反——trd(trend?)=水平、lvl(level?)=趋势，命名互换嫌疑）。
    • sign_value 估值：±1（1=便宜/看多方向）。
    • sign_amtsell 交易拥挤度：实测 0 或 -1（只见非正值，拥挤时 -1 减分）。
    • sign_syn 综合信号（仅 detail 接口出现）、sign_final 最终信号：±1，1=看多、-1=看空。
    • last_sign_final、last_sign_date：上一次相反信号及其日期（实测全部与当前 sign_final 反号 → 记录的是最近一次信号翻转时点）。
  • 方向约定：正=有利/看多，负=不利/看空，0=中性；但各分项档位范围与权重未披露。

9. get_sectoral_signal_final_detail ✅实测（CI005018.CI 医药）

  • 返回最新 30 条（只含 sign_final 非空记录），日频（交易日），最新到 09-02（T+0）。
  • 相比横截面多了：sign_syn 综合信号、sign_tech_desc/sign_policy_desc（实测均 null）、nav_bench 基准净值、nav_strategy 策略净值（字符串型）。
  • 实测医药：nav_strategy 2.757 vs nav_bench 1.038 —— 净值基期未披露；sign_syn 与 sign_final 实测恒相等（疑点：syn→final 是否还有额外过滤，如翻转确认期，无法从数据判断）。
  • 合成线索：8 个分项 → sign_syn → sign_final 的公式/权重完全未披露；从横截面看 sign_final 与 sign_trd/sign_lvl 同号率极高（29/29 中仅交通运输一例 trd=1、final=-1），景气腿疑似主导。

10. queryChinaMacroFactors（中国宏观因子库）✅实测

  • 月频，record_date 为月末（06-30/07-31/08-31），字段 camelCase。返回还带 id/createdAt/updatedAt（可见每日 08:39 批跑刷新，历史行也会被 update）。
  • 16 字段：8 个因子（businessCycleFactor、inflationFactor、inventoryFactor、socialFinancingFactor、excessLiquidityFactor、monetaryVelocityFactor 货币活化、housingMarketExpectationFactor、corporateInvestmentExpansionFactor）+ coreCpi/ppi + monetaryPolicyIntensityFactor + govt10yBondYield + windAllAIndex + 三个周期枚举。
  • ⚠️ 全部数值字段都是标准化后的因子值，不是原始宏观值：实测 govt10yBondYield=-2.19（不可能是收益率原值）、windAllAIndex=5.81（不是 8500 点）、coreCpi=-0.30、ppi=0.60 —— 即使字段名看着像原始指标，也是 z-score 型。用作"查10年国债收益率/万得全A点位"会拿到错误数据，这是本工具最大口径坑。
  • 周期枚举（实测值）：economicCycle=LATE_RECESSION、monetaryCycle=TIGHT_CREDIT_LOOSE_MONEY、inventoryCycle=ACTIVE_DESTOCKING；schema 示例另有 RECOVERY、TIGHT_CREDIT_TIGHT_MONEY、ACTIVE_RESTOCKING，完整枚举表未披露。
  • 当月数据渐进落库：8-31 行的 inflationFactor/coreCpi/ppi/excessLiquidityFactor 等仍为 null（发布滞后），businessCycleFactor 已有值 → 各因子更新节奏不同步。
  • 🐛 实测缺陷：传 columns 参数（严格按 schema 示例 camelCase）稳定报 code 0500 系统异常（两次不同列组合均复现）；不传 columns 才正常。列裁剪功能实际不可用。

11. queryUsMacroFactors（美国宏观因子/择时）✅实测

  • 日频（自然日，周末也有行），返回 records[] + dateRange（整库范围 2004-02-29 起）+ totalCount；同样带 id/createdAt/updatedAt（每日 08:39 批跑，最新到 08-31，T-2）。
  • 原始指标：michiganConsumerConfidenceIndex(51.7)、usPmi(54.6)、usServicesPmi、newHomeSalesAnnualized、housingMarketIndex(35)、usGdpYoy、financialStressIndex(-2.68)、usHighYieldCorporateBondSpread(10.35，疑点：美高收益 OAS 常态 3-5%，10.35 若为 % 意味着极端信用压力，与 financialStressIndex -2.7（宽松）矛盾 → 单位或口径存疑，可能非 OAS 百分比原值)、inflationExpectation(2.34)、usEconomicPolicyUncertaintyIndex(110~347，日度 EPU 指数特征)。
  • 合成层：ecoClimateFactor 经济景气因子(-1.33，z-score)、riskFactor 高频风险指标(0.28~0.47)、ecoPosition 景气仓位、riskPosition 风险仓位、position 总仓位（0/1，实测窗口内恒 0=谨慎）。
  • 回测净值：ixicNsdkNetvalue 纳指净值(12.84) / ixicNsdkStrategeNetvalue 纳指择时净值(11.63) / spxDqsNetvalue 标普净值(6.67) / spxDqsStrategeNetvalue 标普择时净值(7.17)——起点 2004-02-29=1 推断（dateRange 起点），择时不动时净值不变（11.63/7.17 恒定=空仓中）。
  • 稀疏矩阵：低频指标（PMI、密歇根、房产）只在发布日/月末行有值，其余日 null；ecoPosition/riskPosition 近窗口几乎全 null 仅月末行有 ecoPosition=0（疑点：文档说默认 columns=['position','coPosition','riskPosition']，实测不传 columns 返回全部字段，且返回中根本没有 coPosition 字段——文档与实现不符）。
  • 择时逻辑线索：position 疑似 = f(ecoPosition, riskPosition)，两条腿分别对应 ecoClimateFactor 与 riskFactor，但阈值未披露。

四、疑点汇总

数值口径类（高危）

  1. queryChinaMacroFactors 所有数值均为标准化因子值：govt10yBondYield=-2.19、windAllAIndex=5.81、coreCpi=-0.30，字段名与内容严重误导，绝不能当原始宏观值用。标准化方法（窗口、均值方差口径）未披露。
  2. usHighYieldCorporateBondSpread=10.35 与常态 OAS 水平不符、且与金融压力指数(-2.7)方向矛盾，单位/口径存疑。
  3. 两处 dividend_yield 同名不同标的：A股信号 factor（万得全A，1.33%）vs 风格 factor（红利低波指数，4.32%）。
  4. GRRI 可为负 → z-score 型，阈值 1/2/3 应理解为标准差；构成资产、波动率/相关性窗口完全未披露；数值为字符串型。
