04SCENARIO LANDSCAPE

同一套专业能力，
走进十二个业务现场。

先看谁使用、解决什么问题，再看需要哪些输入、交付什么结果，以及由谁承担最终判断。

01 投资者服务

将资金用途、投资期限、风险偏好与账户信息结合，帮助投资者理解配置、产品和市场变化。

输入：用户确认的目标、偏好与授权账户信息
过程：目标梳理 → 账户诊断 → 配置分析 → 约定复盘
交付：可解释的分析、图表报告与持续陪伴
人的职责：投资者确认目标与选择，重要建议由专业人员复核。

02 顾问展业

整合客户信息、账户分析与配置缺口，辅助准备规划报告和沟通内容，让顾问聚焦判断与关系服务。

输入：经授权的客户信息、持仓与服务上下文
过程：信息整理 → 多轮诊断 → 缺口识别 → 顾问跟进
交付：账户诊断、规划参考与沟通准备
人的职责：顾问承担专业判断、客户沟通和后续服务。

03 客服与私域

结合知识检索、产品信息和客户服务上下文，辅助问答、信息整理与沟通草稿，衔接人工服务。

输入：知识资料、问题与可访问的业务信息
过程：理解问题 → 检索依据 → 辅助回答 → 人工衔接
交付：带依据的信息整理与服务沟通参考
人的职责：复杂问题、争议与关键承诺由人工处理。

04 服务质检

在授权范围内辅助分析服务过程，整理沟通质量、服务线索与需要关注的问题，支持顾问评价和复盘。

输入：经授权的服务记录、评价规则与业务上下文
过程：整理记录 → 辅助评价 → 发现问题 → 人工复核
交付：服务评价参考、跟进线索与改进建议
人的职责：AI评价仅作辅助，人员评价与客户处置由机构确认。

05 投研与产品

围绕基金、策略和组合开展查询、比较、诊断与报告整理，支持研究员、产品人员和投顾协作。

输入：基金与策略数据、研究目标及分析规则
过程：取数核验 → 产品分析 → 组合诊断 → 报告交付
交付：基金解读、比较分析与组合报告
人的职责：核对数据时点、模型假设与适用范围。

06 内容与营销

连接素材、数据、观点与图文制作，把内容生产与合规辅助审查放进同一流程。

输入：内容目标、受众、专业素材与数据来源
过程：检索取材 → 研判制作 → 合规辅助 → 人工签发
交付：投顾陪伴内容、图表与渠道素材
人的职责：业务与合规人员核对事实、表达与发布条件。

07 合规与风控

辅助识别内容中的风险表述，定位问题并提出修改建议；结合权限、数据与人工复核约束业务使用。

输入：待审文本或文档、审查策略与产品信息
过程：内容扫描 → 风险定位 → 修改建议 → 人工复核
交付：风险提示、问题位置与修改参考
人的职责：AI辅助审查，机构保留最终合规判断与签发。

08 基金运营

围绕基金公告和运营文档，组织识别、解析、参数提取与校验，为后续业务处理提供数据支持。

输入：基金公告、运营文档与字段规则
过程：文档分类 → 信息提取 → 规则校验 → 异常复核
交付：结构化信息与需人工核查的异常项
人的职责：涉及业务参数和交易的关键操作须另行确认。

09 知识与经营协作

通过文档解析、知识检索与受控工具查询整理信息；对话式经营分析可结合机构数据与权限共建。

输入：授权知识资料、结构化数据与明确业务问题
过程：解析归类 → 检索查询 → 组织依据 → 核对结果
交付：知识问答、信息摘要与分析参考
人的职责：经营问数依赖具体数据对接，不代表独立ChatBI产品已开放。

10 AI 辅助研发

结合AI编程工具、业务上下文与可复用技能，辅助需求理解、代码实现和验证，持续沉淀团队经验。

输入：需求、规范、代码上下文与验收条件
过程：明确任务 → 辅助实现 → 测试验证 → 人工评审
交付：可评审的实现、验证结果与复用技能
人的职责：代码质量、权限操作与上线发布由团队审核。

11 运行治理

将运行监控、日志和业务上下文纳入分析，辅助整理异常与诊断线索，衔接工程师核查和处理。

输入：可访问的运行证据、告警与业务上下文
过程：汇总异常 → 关联证据 → 形成建议 → 人工处置
交付：可追溯的诊断线索与处理参考
人的职责：本页展示治理方法，不承诺自动修复或无人审批上线。

12 机构与生态

提供MCP工具、Skills任务与智能体方案，适配机构既有AI平台、办公入口及业务系统。

输入：明确的业务场景、数据权限与交付目标
过程：选定能力 → 接入对接 → 场景验证 → 验收迭代
交付：工具接入、联合方案或专属场景智能体
人的职责：可用目录、数据范围与服务责任按项目确认。

地图同时呈现公开产品、企业实践和可组合场景。经营问数、智能运维等需结合机构系统与权限共建，企业内建能力的展示不代表同名标准产品已开放。流程为解释性示意。[14]
