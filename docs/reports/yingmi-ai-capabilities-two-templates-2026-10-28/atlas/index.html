01 / 账户与家庭规划

以目标与授权账户信息为起点，把诊断交付衔接到用户和顾问。

  1. 目标与授权 · 确认用途、期限、偏好与数据边界。
  2. 诊断与配置 · 调用金融工具，梳理账户与配置差异。
  3. 报告与解释 · 呈现依据、假设及需要进一步了解的问题。
  4. 确认与复盘 · 用户或顾问确认，按支持的任务设置约定复盘。
02 / 投研监测

将取数、专业方法与报告交付组织为持续任务。

  1. 定义任务 · 确认基金池、指标、频率与提醒条件。
  2. 获取数据 · 按权限读取净值、持仓与市场信息。
  3. 执行分析 · 组织比较、风险观察与变化解释。
  4. 交付与核验 · 核对报告依据、统计时点及任务状态。
03 / 内容生产

从取材到发布前审核，让业务与合规更早协同。

  1. 受众与素材 · 明确目标，检索内容与相关资料。
  2. 取数与制作 · 核对依据，形成文案、图表等素材。
  3. 辅助审查 · 识别风险表述，提供位置和修改建议。
  4. 复核与签发 · 业务与合规人员确认事实和发布条件。
04 / 服务与质检

在授权数据与评价规则之内，为服务人员整理信息。

  1. 规则与授权 · 确认记录、评价维度与使用目的。
  2. 整理上下文 · 提取关注点、已有信息与待核事项。
  3. 辅助评价 · 形成质量观察、沟通草稿与跟进线索。
  4. 人工服务 · 顾问或服务负责人复核并决定后续处理。
05 / 公告与运营

识别、提取、检查与复核连接成可追溯的处理过程。

  1. 确认文档 · 识别类型、来源与待提取字段。
  2. 提取信息 · 按业务语义与字段规则组织内容。
  3. 检查异常 · 发现缺失、冲突与待复核事项。
  4. 业务确认 · 关键结果由人员确认后进入业务流程。
06 / AI 辅助研发

用业务上下文和工程规范约束辅助研发。

  1. 明确边界 · 整理需求、权限与验收条件。
  2. 辅助实现 · 在可用上下文中完成设计与代码准备。
  3. 验证修订 · 核对功能、测试结果和影响范围。
  4. 评审发布 · 团队确认质量与发布条件，沉淀经验。
07 / 运行诊断

辅助工程师调查，关键操作保留权限与人工确认。

  1. 汇总异常 · 明确时间窗口、异常现象与影响对象。
  2. 关联证据 · 整理可访问的日志、指标与业务上下文。
  3. 形成线索 · 区分观察事实、可能原因和待验证事项。
  4. 处置复盘 · 工程师核查、决定操作并记录处理结果。
