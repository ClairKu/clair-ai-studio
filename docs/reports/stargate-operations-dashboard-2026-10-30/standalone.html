聚合一致性与缺失值自检

    合计口径与覆盖范围

    调用合计
    记录调用合计 = API Key 日聚合调用 + OAuth MCP 成功调用。它表示两类记录的组合范围，构成始终保留，不宣称统一业务成功执行数。
    主体与复用
    使用主体合计 = 使用 Key + OAuth 区间去重账户，为未跨来源去重的身份主体数。复用主体合计按各来源内跨 ≥2 日计算，复用率重算分子／分母；不相加百分比。同一 OAuth 来源的每日／平台账户数不能求和替代区间去重。
    时间与缺口
    日期按上海自然日；10/30 尚未完整。OAuth 10/29 前为 null，这些日期的已观测合计仅覆盖 Key；采集开始后，已确认平台在已采集日无记录才可为 0。完整日日均用同一批完整日的合计记录除以天数。
    窗口成熟度
    OAuth 只有两天，不能作环比、同比、增长或周月留存结论。跨日复用率不等于留存率。
    其他维度
    平台分布仅 OAuth 可归因，筛选平台时只看 OAuth，不拼入全量 Key。工具与机构尚无两侧对齐数据，暂无法合计，不造数。
