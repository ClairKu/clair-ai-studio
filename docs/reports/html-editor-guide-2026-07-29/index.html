日常改几个字时，可以先保留为当前浏览器会话草稿，不必马上动生产档案。

1

打开报告

从成果库进入任一可直接访问的 HTML 报告，顶部栏会出现“编辑文档”。

2

修订并暂存

修改后显示“已修订”；点击“暂存”后保存在当前浏览器会话，不写 GitHub。

预览或下载

4

暂存与生产发布架构

GitHub Pages 是静态托管，因此工作台把日常修订与生产写回拆成两个明确阶段。

REPORT隔离编辑画布

报告脚本与内联事件在编辑时停用；画布没有同源权限，无法读取父页面 Token。

→
SESSION DRAFT浏览器会话暂存

当前修订只存在本次浏览器会话；可恢复、预览或下载，不触发 GitHub。

→
GITHUB PRODUCTION确认后写回

二次确认后读取最新 SHA 并提交；权限不足会停止，暂存内容仍保留。

首次推送生产：权限怎么配

推荐 Fine-grained personal access token
  1. Resource owner 选择 ClairKu。
  2. Repository access 仅选择要编辑的报告仓库。
  3. Repository permissions 仅开启 Contents: Read and write。
  4. 设置明确的过期时间，复制 Token 后粘贴到“保存权限”。
重要安全限制

Token 等同密码。它只保存在当前页面的 JavaScript 内存中，刷新即清除；浏览器会话暂存不包含 Token。公共静态站无法提供服务端密钥保险箱，若要长期免 Token 推送，应升级为 GitHub App + 后端函数。

边界与处理方式

情况当前处理你会看到什么
ClairKu GitHub Pages 报告自动推断仓库、分支与 HTML 路径。可编辑，可使用 GitHub Token 写回。
只想临时修改点击“暂存”，保存到当前浏览器 sessionStorage。显示“已暂存·待推送生产”，不会更新 GitHub。
现有 AES-GCM 加密报告解密正文编辑，输出与保存时重新生成盐和 IV 并加密。编辑体验是明文，生产文件仍需口令。
登录型或组织内报告不尝试绕过登录与跨域限制。继续在原站点打开；不显示“编辑文档”。
非 GitHub 或跨域不允许读取读取失败时停止编辑，保留原页面入口。提示具体原因，可尝试下载或手动配置源文件。
