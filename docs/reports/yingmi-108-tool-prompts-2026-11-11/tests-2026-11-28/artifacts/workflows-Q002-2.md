# “跌15%会焦虑”不等于风险测评

M29能支持“甲在2026-11-09表达过对短期下跌的焦虑”，不能支持其正式风险等级、实际损失承受能力或今后的交易行为。

| 维度 | 已有证据 | 仍未知 |
|---|---|---|
| 主观感受 | 甲自述短期跌15%可能焦虑，来源M29、2026-11-09 | 焦虑对应哪笔钱、何种损失口径、是否影响生活 |
| 经验事实 | 没有其本人已实现亏损或过往交易记录 | 是否经历过同量级波动及当时处置 |
| 流动性 | 应急金30万元不挪用；改善目标可延后；教育优先，来源M07/M29 | 新的刚性用款、负债条款及资产是否受限 |
| 实际风险能力 | 只有模拟资产负债和收支，不能单凭净资产高低作最终结论 | 有效测评、生活底线、损失对各目标的影响 |

澄清问题：①“15%说的是整个家庭资产、投资账户，还是某只基金？”②“如果亏损持续一年，会影响哪项已确定的开支？”③“过去遇到类似波动时，你实际怎么处理？”④“希望先解释波动原因，还是先核对用款与可退出条件？”

顾问假设：客户可能需要明确资金桶、损失口径和过程解释；置信度仅中等，因为来自一次自述。复核触发是目标/收入变化、风险测评补齐或客户纠正原话。内部材料不用“激进/保守”“高风险/低风险客户”标签，不推荐基金。
