# 顾问私聊回复与内部算式

基金涨幅看净值区间，个人盈亏看每笔钱的投入、回款和剩余份额。M06只是模拟流水，缺期末净值，暂不能判断赚亏。请补期末份额、净值、申赎和分红明细后核对；分红也不是额外收益。

## 顾问内部计算说明
M06实际读入：累计买入61,000元，卖出到账11,500元，现金分红300元，剩余12,500份。没有期末净值，故不能算真实期末资产或真实收益率。

仅为算术演示：若假设期末单位净值3.9元，期末市值48,750元，累计现金盈亏=48,750+11,500+300−61,000=−450元；若假设4.2元，则期末市值52,500元，累计盈亏3,300元。用总投入61,000作分母分别为−0.74%及5.41%，是明确指定分母的简化比例，不是IRR、时间加权收益或平台持有收益率。

另一口径采用移动平均成本示例：买入平均成本61,000÷15,000=4.066667元/份；赎回2,500份对应成本10,166.67元，已实现利润1,333.33元，剩余成本50,833.33元。假设期末3.9元，持有浮亏2,083.33元，已实现利润与分红合计1,633.33元，累计仍为−450元。此算法是教学假设，不能冒充且慢账户实际算法。
