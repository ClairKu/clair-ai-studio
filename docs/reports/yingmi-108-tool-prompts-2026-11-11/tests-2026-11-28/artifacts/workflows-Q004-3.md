# 降薪一年：先保安全底座，延后改善目标

压力年度仍有正结余117,600元，但若同时按月积累教育金6,000元及三年改善资金5,555.56元，会每月超出结余1,755.56元。应急金30万元不挪用；优先考虑延后改善，而非提高收益假设。

|项目|基准年度|工资降20%、无奖金12个月|
|---|---:|---:|
|工资|552,000|441,600|
|奖金|60,000|0|
|收入合计|612,000|441,600|
|既定年度支出|324,000|324,000|
|年度结余|288,000|117,600|
|平均月结余|24,000|9,800|
|扣每月教育积累6,000后|18,000|3,800|
|再扣改善资金月积累5,555.56后|12,444.44|−1,755.56|

这里的6,000元是未来大学的专用储蓄，不是M09中已包含的当前教育支出；二者用途不同，避免把同一支出重复计入。平均月结余将奖金按年平均，不等于每个月实际到账，执行预算仍应按到账日核对。

可推迟：三年改善20万元，降薪年度暂停该项积累；不能把既定付款说成已可延后，需客户确认。可压缩：旅行预算24,000元/年等非刚性项目，最多释放每月2,000元，是否削减由家庭选择。需补证：社保养老金、保险责任、房贷利率与剩余期限、奖金稳定性、赡养支出变化。养老资金缺少可靠养老金和现有专用本金边界，不能把本年度剩余结余直接认定为养老已达标。

本题完成一年预算压力测试及目标冲突排序，没有伪装为30年全周期退休资金模拟。后续若需全周期，须补齐增长、通胀和养老金假设，再调用现金流能力。
