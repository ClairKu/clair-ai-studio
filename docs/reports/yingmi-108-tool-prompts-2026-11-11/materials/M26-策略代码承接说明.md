# 策略检索与标识承接

> 模拟案例／教学测试；此文件不含伪造策略代码。

输入关键词可用“我要稳稳的幸福”“花好月圆”“全球丰收”，它们来自官网当前引导提问，仅作检索字符串，不预设工具一定有结果。先调用StrategySearchByKeyword，检查返回名称、管理人或说明是否对应目标；将唯一匹配结果中的代码原样作为strategyCode或strategyCodes。多条重名则先展示候选供确认，零结果停止依赖查询并说明；不可用中文名称、案例编号或其他产品代码替代。

后续按各工具Schema分别传单个代码或数组；持仓、交易成分、资产穿透、业绩基准、详情、费率和风险信息都不是同一个数据。先保存搜索所得实际代码、匹配名称、查询时点与来源，用于最终回答可核查。

若单工具演示环境不能调用搜索，请从已连接的策略搜索结果中粘贴代码后再运行；标注“需连接后补参数”。不把此前截图中的代码当当前有效代码。
