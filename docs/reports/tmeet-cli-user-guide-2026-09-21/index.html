腾讯会议 CLI 上手手册

装一次，以后开会的事直接跟 AI 助手说一句话就行。不用懂技术，照着做 10 分钟。

你需要：一台电脑 腾讯会议账号（平时开会用的那个） 一个 AI 助手（Claude Code、WorkBuddy、Codex 都行）

?装好以后能干什么

在 AI 助手的聊天框里，像跟同事说话一样说：

帮我约明天下午 3 点的周会，开 1 小时
把周三那场评审会的纪要给我，列出待办
今天上午那个客户会都谁来了？谁中途走的？
上个月哪场会提到过「预算」？
把明天那个会改到下午 4 点

它就会去你的腾讯会议里把事办了。只能碰你自己账号里的会，看不到别人的。

1安装：把这句话发给你的 AI 助手

这是最省事的办法。AI 助手会自己把工具装好，中间只需要你在浏览器里点一次「同意」。

复制这句话，发给 AI 助手
帮我安装腾讯会议CLI，链接地址：https://meeting.tencent.com/wemeet-tapi/v2/oauth2/oauth/cli-install-guide?ch=web
  1. AI 助手开始安装

    会跑一两分钟，期间它可能问你「是否继续」，回它「是」就行。

  2. 浏览器自动弹出一个腾讯会议页面

    用你平时开会的账号登录（微信扫码或手机号），然后点「同意授权」。这一步是在腾讯会议官方网站上做的，密码不会经过 AI。

    看到「授权成功」就对了

  3. 把 AI 助手完全退出，再重新打开

    不重启它记不住新装的东西。重开后跟它说「查一下我这周的会议」，它能答上来，就全部搞定。

    以后 30 天内都不需要再登录

浏览器没有自动弹出来？ 看一下 AI 助手的回复，里面有一个以 https://meeting.tencent.com 开头的链接，自己复制到浏览器打开就行。
AI 助手装不了？手动装也就 3 行命令

先打开「命令窗口」：Mac 按 ⌘+空格，输入「终端」回车；Windows 按 Win 键，输入「PowerShell」回车。会出来一个黑色或白色的输入框。

第 1 行：装工具。粘贴进去，回车，等 10 秒。

npm install -g @tencentcloud/tmeet

装完再输 tmeet -V，看到 tmeet version v1.0.xx 就对了。

第 2 行：登录。粘贴回车后浏览器会弹出腾讯会议授权页，登录并点「同意授权」。

tmeet auth login

窗口里出现绿色的 Login successful 就对了。

第 3 行：教 AI 助手怎么用它。粘贴回车，中间问「是否安装」就输 y 回车。

npx -y skills add TencentCloud/tencentmeeting-cli -y -g

出现绿色的 ✓ tmeet-skill 就对了。最后把 AI 助手退出重开。

第 1 行提示 command not found？ 电脑上缺一个基础软件 Node.js。去 nodejs.org/zh-cn 点绿色「下载 LTS」，像装普通软件一样装完，关掉命令窗口重新打开，再来一遍。
Mac 上第 1 行提示 permission denied？ 公司电脑常见，把第 1 行换成下面这行就行，其余不变。
mkdir -p ~/.npm-global && npm install -g --prefix ~/.npm-global @tencentcloud/tmeet && echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc

2使用：直接说人话

不用再碰命令窗口了。想到什么说什么，AI 助手会自己去查、去约、去改。几个小提醒：

  1. 改时间、取消、邀请人之前，AI 会先复述一遍问你「确认吗」

    因为这些事会影响别人或者没法撤销。你回「确认」它才动手。这是故意设计的，不是它没听懂。

  2. 要纪要，会议得开过「云录制」或「元宝纪要」

    没开的会只有时间、参会人这些基本信息，没有内容。

  3. 只能看你参加过的会

    别人的会、别人的通讯录，它查不到，也不会帮你查。

3出问题了怎么办

AI 说「找不到 tmeet」或「没有安装」
大概率是装完没重启 AI 助手。完全退出再打开。还不行就把第 1 部分那句话再发一次让它重装。
AI 说「未登录」或 user config is empty
跟它说「帮我登录腾讯会议 CLI」，浏览器再点一次授权就好。
AI 说这场会「没有录制」，但我明明录了
可能录制是别人开的，你还没权限。跟 AI 说「帮我申请这场会的录制权限」。如果录制设了密码，得找录制的人要密码。刚结束的会还在转码，等几分钟再试。
我是企业版账号，登录报错
企业版目前要先找腾讯会议申请开通。个人版、专业版直接就能用。可以先找 IT 或群里问一下公司账号有没有开。
换电脑了 / 不想用了
换电脑：在新电脑上把第 1 部分那句话再发一遍。不想用了：跟 AI 说「退出腾讯会议 CLI 登录」，它会帮你注销授权。
一条安全提醒 AI 助手拿到的权限等于你本人，能看到你的会议纪要和录制。别把电脑上 .tmeet 这个文件夹发给任何人；怀疑账号有问题，跟 AI 说「退出腾讯会议 CLI 登录」即可切断。
