PRODUCT BRIEF · 产品系统介绍

YingmiWork：盈米自己的 AI 工作台

一个装在投顾电脑里的「数字员工」——登录就能聊、同事的做法能装成技能、知识写得进去找得回来、企业微信里直接叫它干活。

产品名 YingmiWork（应用为 WealthWork.app） 当前版本 v0.0.4 内测（2026-08-17） 平台 macOS（Apple / Intel 双芯片） 范围 仅限盈米员工 · 盈米账号登录

一这是一个怎样的系统

YingmiWork 是盈米基金面向内部的 AI Agent 桌面工作台：外观是一个对话框，内核是一个能真正动手干活的智能体运行时——它可以读写本机文件、执行命令、调用公司内部系统（Wiki、Redash、生产库、可观测平台……），每一步关键动作都要经过用户审批，全程留痕。

与「网页版聊天机器人」的本质区别在于三点：

  • 它在你的电脑上干活——本地 Agent 引擎（FinClaw）跑在本机，能操作真实的文件与工具，而不是只会输出文字；敏感操作有「始终允许 / 允许一次 / 拒绝」审批闸门，可选 FinSafe 沙箱包装 Agent 进程。
  • 能力是组织资产——「技能市场」把同事沉淀的做法（Prompt + 脚本 + 触发条件）做成可订阅的技能包，装上就会；自己的做法也能上架，可只发给本组。
  • 合规是底座——界面常驻「信任域：本地 · 审计留痕 10 年+」，对话与每次工具调用全部落库本机 SQLite，符合投顾展业的留痕要求。
「登录就能聊，什么都不用配。模型额度、数据连接、常用技能都配好了，不用自己申请 key。」 —— 官方下载页（ai.yingmi-inc.com/yingmiwork）

二产品定位、目标与客群

定位
投顾的数字员工

官方口号「改变中国投顾的工作方式」。不是又一个聊天窗口，而是「您贴心的投研、服务、运营助手」——把投顾每天重复性的查数、写稿、处理客户任务交给 Agent。

目标
零门槛 + 能力复利

内测期聚焦「四件事」：开箱即用、Skills 管理、知识管理、链接微信。核心赌注是让业务同事无需任何配置就能用上，且组织内的最佳实践通过技能市场滚雪球。

客群
盈米内部员工

内测仅限盈米员工，盈米账号（企微/KC）登录。首要画像是投顾/理财师（MOT、客户匹配、投资规划六步法），同时覆盖投研、运营与研发（Redash、Wiki、线上排查类技能已上架）。

五使用指引

  1. 下载安装（对准芯片）

    下载页 ai.yingmi-inc.com/yingmiwork。「关于本机」写 Apple M 系芯片选 arm64 包，Intel 选 x64 包——下错打不开。内测包未做公证，首次打开若被拦：应用程序里右键图标 → 打开；仍不行在终端执行 xattr -dr com.apple.quarantine /Applications/YingmiWork.app。

  2. 登录即完成全部配置

    用盈米账号走浏览器授权。登录后模型额度、数据连接、常用技能（含 ym-skill-hub）自动就位，无需申请任何 API key。之后新版本应用内自动提示更新。

  3. 发起第一个任务

    首页输入框直接描述业务任务（参考内置示例「批量处理今天所有 L1 的 MOT」）。Agent 需要执行命令或读写文件时会弹审批——看清命令再选「允许一次」，高频可信操作再给「始终允许」。过程条可展开看它每一步在干什么。

  4. 按岗位订阅技能

    技能市场 → Skills 广场，先点「详情」看「何时触发」，判断和自己工作匹配再订阅。投研/数据岗常用：redash、prod-db-query、sensor-skill；研发岗：ym-infra、jira-query、wiki；技能作者：skill-creator + ym-skill-hub（制作并上架，可只发本组）。

  5. 接入微信（可选）

    IM 渠道 → 微信 → 扫码登录，指定对话 Agent 与模型。之后在微信里直接下达任务，会话与桌面端同一套，标题以「[微信]」开头便于区分。

  6. 按偏好调两处设置

    设置 → 外观 → 过程步骤显示：想盯着它干活选「完整」，读历史多选「精简」，默认「跟随」两头兼顾。设置 → 系统：对不放心的场景可开启 FinSafe 沙箱；长任务可调大 LLM 超时。

内测版使用提醒（基于 2026-08-20 对 0.0.4 的实测）：当前构建存在「最终回答不渲染」的严重缺陷——回答内容实际已生成并落库，但界面可能只显示时间戳；另有附件预览无响应、图片附件发送后不显示两处问题。遇到空回答不是任务失败，等修复版或联系研发导出即可。详见配套《验收测试报告》。
