System map

产品真正的主链路：发现机会，再把机会变成可审核物料

四块页面并非平行孤岛。Skill 库提供可复用方法，机会引擎决定“现在做什么”，固收工作台把组合数据变成陪伴内容，定制方案页承载资产配置研究。缺口在最后两步：合规只做关键词级过滤，执行记录也未与真实客户、触达、成交结果闭环。

Metric dictionary

指标与公式：哪些是事实，哪些是规则，哪些只是启发

机会与状态规则

当前状态
净值缺失 → 缺失；否则创新高 → 新高；否则当期回撤绝对值 ≥ 5% → 回撤；其余为稳定。
排序
高紧急度优先，其次中、低；同级按日期由新到旧。
固收预警
连续下跌天数 ≥ 3；或当前回撤达到历史最大回撤幅度的 70% 以上。
合规扫描
22 个红线词做字符串命中 + 3 条必备风险语句缺失检查。通过仅表示“未命中规则”，不是法律意见。

收益与风险口径

区间收益
R = NAV_end / NAV_start − 1
年化波动
σ_annual = sampleStd(daily returns) × √252
Sharpe
Sharpe = (区间年化收益 − 1.5%无风险利率) / 年化波动
Calmar
Calmar = 区间年化收益 / |区间最大回撤|
超额
Excess = Portfolio return − Benchmark return

滚动统计与回撤

正收益率
每个交易日作为起点，持有自然 3 月/6 月/1 年/2 年；收益 > 0 的样本数 ÷ 有效样本数。
回撤
DD_t = NAV_t / max(NAV_0…NAV_t) − 1
修复天数
从前高到净值重新达到前高的自然日天数；未恢复必须显式标注。
统计警告
滚动窗口高度重叠，并非独立样本；“100% 正收益”不能外推为未来概率，尤其样本只有 57 时。

情绪与组合目标

情绪分
标题命中词权重为摘要的 2 倍，正负词频归一化到 −100…100；经理观点 >15 为积极、<−15 为谨慎，其余中性。
目标风险映射
目标 ≥ 8% → R4；目标 ≥ 6% → R3；其余 → R2。
目标差
Gap = 成立以来年化收益 − 战略目标
边界
3%–10% 是组合目标标签，不是预测或承诺；词典情绪分是内容索引信号，不是市场方向模型。

Representative use cases

六类典型使用场景，决定这套库能否转化为生产力

01 · 监控

创新高后的运营动作

机会引擎发现新高 → 拉取净值/基准/回撤 → 运行“新高营销”或“要不要卖” → 合规扫描 → 运营复核后生成 H5。必须区分营销与决策，不能用同一套单向挽留话术。

02 · 陪伴

固收策略连续下跌

连续下跌 ≥3 日或回撤接近历史阈值 → 核对期限与原因 → 选历史窗口和经理观点 → 输出解释/行动边界。当前情绪分只能当线索，不能替代投研判断。

03 · 配置

新资金方案

录入可投资金、期限、风险与流动性 → 四笔钱映射 → 调取真实策略数据 → 形成金额、比例与风险提示。若实时策略接口缺失，应停止产品推荐，不能套静态示例。

04 · 复盘

策略亏损诊断

识别峰值、回撤、修复史和市场周期 → 判断策略机制是否失效 → 给持有、减仓或退出条件。技能明确要求“数据指向该走时如实说”，不能把留存等同于死扛。

05 · 内容

从早报到私域日报

只读用户提供的早报文档 → 提炼市场变化与普通投资者影响 → 去 AI 味 → 过营销合规 → 输出纯文本/推送。来源边界清晰，是当前最容易规模化的链路。

06 · 计算

客户持有单价

交易流水结构化 → 移动加权平均或主理人特定算法 → 对账份额/本金/卖出到账 → 输出可复核明细。三项计算技能已纠正费率方向文字，仍应保留逐笔校验。

Risk review

最需要先修的不是 UI，而是身份与数据责任边界

P0 · AUTH

前端登录不是授权

页面公开脚本包含静态登录材料，并在浏览器端持有匿名数据访问配置。若后端行级策略不严，攻击者可绕过 UI 直接访问数据。本次没有进行破坏性写测试，因此写入风险仍是“未验证高风险”，不能宣称安全。

P1 · DATA

来源与时点未统一

净值日、接口刷新时刻、观点发布日期、材料窗口和独立看板数据各自存在。每个数值都应同时携带 source / asOf / generatedAt / formulaVersion。

P1 · CLAIM

规则分数容易被误读

情绪分、估值温度、机会紧急度、目标收益和正收益比例都不是收益承诺。页面需要把“事实、规则计算、模型推断、运营建议”视觉分层。

安全处置建议：立刻废弃前端静态凭据；切换企业 SSO/短期令牌；只允许服务端读取数据；逐表检查行级策略；将上传、编辑、评论、处理状态等写操作纳入角色权限和审计日志；在完成授权测试前，禁止接入真实客户数据。
