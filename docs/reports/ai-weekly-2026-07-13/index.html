一、AI开放平台

本周重点是两条外部 AI 入口合作：千问 App 接入盈米 AI 能力、微信小程序接入微信 AI 推荐生态。同时，OAP / Stargate / MCP / Skills 继续补齐开放平台底座，支撑后续能力展示、授权、上架和商业化。

最新数据能力资产与上架进度

  • Skills 中台本周新增 3 个，当前已有 19 个 Skills，其中 9 个待上架。
  • 已重新梳理全部 MCP 接口，初步确定下一批要上线的 MCP 和 Skills 清单。
  • 7.31 前计划新增若干 Skills 和 MCP 到 OAP，并规划一批 Agent 在百炼、Workbuddy 上线。
  • 对外平台已完成 MCP 多平台露出，后续重点转向 Agent 上架与商业化验证。

能力建设OAP / Stargate / 治理

  • OAP 官网 v2.0 PRD 和原型调整中，降低独立账号体系优先级，加入 SSO 登录相关设计。
  • 新增积分消耗机制，为后续付费与商业化提前准备。
  • Stargate 根据 OAP 二期需求推进，MCP 发布审核功能已完成开发。
  • 盈米 AI 开放能力治理已初步完成，后续可支撑能力目录、权限、上架、审核和使用追踪。
