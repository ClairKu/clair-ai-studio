02 / Sources & Definitions

数据来源与口径

申请／授权覆盖：API Key申请表按账号去重；缺失账号时，用申请明确关联的Key补齐，再加上 qieman 对客渠道主动交互授权用户；排除已识别测试 Key 和测试客户端。累计保留已撤销或被替代的授权。排除已识别测试后，Key申请表共15,411条、当前均已批准；原有50条缺账号的申请通过关联Key补齐5条（净补1个账号），双方账号冲突0，仍有45条无法映射，未折算人数。账号可有多条申请；历史删除记录完整性未审计。

调用：API Key 调用日聚合（可见起点2025/5/7）与 OAuth 调用日聚合相加，采用全空间口径。两侧成功判定、调用层级及请求去重尚未统一，不能据此计算业务成功率。

月活：10/3—11/1窗口内有调用记录的账号去重。Key按绑定用户去重；OAuth覆盖全部身份域，包括自动预授权、内部及测试渠道。OAuth中且慢2,079、yingchat 17、ympkc 4；仅在同一且慢身份域匹配 Key，其他身份域保留独立身份。

不能混用：API Key对象数15,946不等于申请用户15,361；近30日另有91个活跃Key没有个人映射，未折算进月活账号。申请行与使用行不是同一人群，不能用本表计算申请转活跃率。

来源为生产只读聚合，原始个人标识、Key、Token和明细未进入本页。各来源取数时刻保存在下载数据包中；所有指标采用相同截止日。
