“都发布”不等于把内部数据搬到公网

Clair 工作台部署在公开 GitHub Pages。访问口令是前端体验控制，不是保密边界。因此发布判断逐件进行，不能用一次授权替代所有数据出境判断。

可以公开

  • 经过脱敏的产品方案、竞品研究与交互 Demo
  • 示例数据、明确假设、公开来源与非敏感聚合结论
  • 不含客户、账号、Key、请求、交易和内部权限的信息

默认不公开

  • 客户或用户级持仓、交易、提问、行为和绑定数据
  • 机构使用量、计费、Key 结构、请求内容与经营明细
  • 内部 Prompt、系统 ID、接口、库表、权限和安全配置
