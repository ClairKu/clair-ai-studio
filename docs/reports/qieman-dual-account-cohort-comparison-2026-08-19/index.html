条长表示回撤深度（越长跌得越深）。为近 3 个月窗口内回撤，非开户以来历史最大回撤；排序与波动率完全一致。
一句话结论：双持用户不是收益率最高的（仅长钱 34.08% 最高），但综合体验最优——拿得最久（3 年+）、人均赚得最多（3.7 万元，为仅长钱的 2.3 倍）、近八成人赚钱（接近稳钱组），而波动与回撤都只有纯长钱的约 3/4。稳钱打底 + 长钱进攻的账户结构，用更平的持有体验换来了更长的持有期。
注意：这是观察性分组而非实验——双持用户往往本金更大、投资更成熟，指标差异是「相关」而非「配置双账户导致」。累计收益率还受入场时点、资产规模路径影响（资金加权），跨组比较需谨慎。

口径说明

来自盈米本体的下钻记录，关键假设逐条列示。
  1. 稳钱 / 长钱界定：且慢「四笔钱」分类，po_config_info.m4_type（LONGTERM=长钱 / STEADY=稳钱 / SPARE=活钱），371 个组合全覆盖（长 257 / 稳 109 / 活 5）；用户在某类组合持仓资产 > 0 即计为「持有该类账户」。
  2. 分组快照：asset_analysis_report_user_behavior 2026-07 月度全量快照（42.7 万用户，全部 broker 0008），按 steady_asset / longterm_asset 是否 > 0 切三组；「既无稳钱又无长钱」的 98,028 位用户已排除。
  3. 收益数据：dwd_app_service_account_profit_combine（SA 树 ROOT 层，cal_date=2026-07-31），经 portfolio_manager_info（ACTIVE）做 ID 映射后关联；映射覆盖 326,657 / 329,188 ≈ 99.2%，缺口来自销户与数据未就绪。
  4. 时间窗口：收益率 / 盈利占比 / 持有时长为开户以来累计（截至 2026-07-31）；波动率为近 3 个月（2026-05-01 ~ 07-31）。两类窗口不同，跨指标解读时注意。
  5. 波动率抽样：全量近 3 月日收益明细约 2,640 万行，聚合查询连续超时，改为 account3_id % 20 = 0 的 1/20 确定性抽样后跑通；抽样与全量同分布，方向可信、数值含抽样误差。
  6. 最大回撤口径：近 3 个月窗口内净值回撤（非开户以来历史最大回撤），用 fof_nav（累计 TWR+1，不受申赎资金进出扰动）按日取累积峰值算 peak-to-trough，1/100 确定性抽样（account3_id % 100 = 0），报组内均值；个别账户窗口内净值一路新高则回撤为 0%。
  7. 收益率口径取舍：主口径 acc_mwr（资金加权，考虑申赎现金流）；acc_twr（时间加权）因异常账户极值拉高（双持组均值 169%）弃用；另附「费后收益 ÷ 历史最大本金」作交叉参考。
  8. 数据通道：盈米本体经 redash ds41（TiDB 数仓）兜底查询；首选 MaxCompute 用户级宽表因 ODPS 凭据不可用未走通。
