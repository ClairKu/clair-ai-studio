持仓风险诊断 · risk-scope

把「你的风险舒适区」和「持仓的晨星风险分」放在同一条 0–100 刻度上，看清落点过低 / 匹配 / 过高，并给出可验证的再平衡建议。

后端强版本 · 全实时真值 · 需本地 / 内网后端运行
为什么这是说明页而不是在线应用：本工具是 Node 后端服务（server.mjs），所有风险数值都来自盈米内部真实接口（组合晨星分、舒适区五段、策略成分拆解）， 没有 mock、没有假数据。它依赖内网可达的 uaap-gateway / pomodel，无法部署为纯静态公网页面，因此在工作台以说明卡片呈现。 需要完整交互的离线版请用同系工具「风险透镜」（工作台另一张卡片，浏览器直接可玩）。

三条轴 · 不可混用

  • 适当性总分 0–100（抗风险值）—— 风测结果，分档 C0–C5。
  • 晨星风险分 0–100+ —— 标的与持仓风险；上界非 100（招商中证白酒实测 127.3）。
  • 协会风险等级 R1–R5 —— 合规等级，只用于适当性匹配，与晨星分不可换算。
