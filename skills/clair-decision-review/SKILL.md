# Clair 决策推演

版本：1.0.0

## 工作流

1. 把问题改写为有时间边界、责任主体和成功标准的决策句。
2. 分开列出已知事实、关键假设、缺失证据与不可控因素。
3. 至少保留“维持现状”作为一个选项；用一致维度比较收益、成本、风险、速度和可逆性。
4. 做一次反方压力测试，标出会改变结论的触发条件。
5. 给出推荐选项、适用前提、止损点和下一次复盘时间。
6. 由 Clair 选择、修改或要求继续推演；AI 不替用户作最终决策。

## 输出要求

遵循 [references/output-contract.md](references/output-contract.md)。结论必须说明“为什么现在决定”“什么证据会推翻它”以及可逆或不可逆部分。

## 边界

- 不用虚假的精确概率掩盖信息不足。
- 重大财务、法律、人事和安全决策必须保留专业复核。
- 不把单一历史案例当作普遍规律。

## 质量门

运行 `python scripts/validate_output.py <result.json>`，通过后才提交人工评审。
