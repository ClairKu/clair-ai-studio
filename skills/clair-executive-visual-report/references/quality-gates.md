# 质量门

## 内容

- 首屏 10 秒内可读出结论、对象、时间和边界。
- 每章标题是判断句；章节顺序形成一条论证链。
- 事实、推断、缺失、目标态以状态标签区分。
- 数字带日期和口径；图片带说明、来源和替代文本。
- 下一步包含动作、责任、时间或明确的待确认项。

## 视觉

- 桌面端正文最大宽度 1180px，阅读行长不过长。
- 390px 下单列展示，按钮可点，文字不小于 12px，无横向溢出。
- 深色章节仅用于演示、关键转折或收束，避免全页高对比疲劳。
- 一屏只突出一个主视觉；图表与装饰必须服务信息关系。
- 中文标点、字体回退和长英文/URL 不破版。

## 技术

- HTML 可离线打开，无 CDN、远端字体和运行时构建依赖。
- 页面含 `lang=zh-CN`、viewport、标题、描述、跳转主内容与键盘焦点。
- 图片使用相对路径并在发布目录真实存在；懒加载不影响首屏。
- 尊重 `prefers-reduced-motion`；打印时隐藏导航和交互按钮。
- `report.json` 与 HTML 均通过校验脚本。

## 发布

- 保存原始材料、研究源、结构化 JSON 和生成 HTML。
- 内部敏感材料先加密正文，再检查公开源码无明文。
- 工作台只保留一个稳定生产入口，不重复登记 URL。
- 构建、测试、`git diff --check` 后推送；等待 Pages 成功并验证 HTTP、标题、资源、桌面和移动端。
