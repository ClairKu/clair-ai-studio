# 质量门

## 内容

- 首屏 10 秒内可读出结论、对象、时间和边界。
- 每章标题是判断句；章节顺序形成一条论证链。
- 事实、推断、缺失、目标态以状态标签区分。
- 数字带日期和口径；图片带说明、来源和替代文本。
- 下一步包含动作、责任、时间或明确的待确认项。

## 视觉

- 桌面端正文最大宽度 1180px，阅读行长不过长。
- 390px 下单列展示，按钮可点，文字不小于 12px，无横向溢出。
- 深色章节仅用于演示、关键转折或收束，避免全页高对比疲劳。
- 一屏只突出一个主视觉；图表与装饰必须服务信息关系。
- 每个正文模块固定为一个可视屏高；内容超量时仅模块内部滚动，不撑破外层分屏。
- 鼠标滚轮/触控滑动结束后吸附到完整模块，右侧页轨能准确显示和点击定位当前屏。
- 全页面统一使用宋体字体族；桌面端导航高度不超过 54px，移动端不超过 50px。
- 章节标题控制在 16 个字符、一到两行，正文模块标题不超过 36px；标题带必须裁切溢出，不能遮挡核心内容区。
- 当前章节导航项自动平滑滚到导航中部，前后至少各保留一个章节入口可见（边界章节除外）。
- 页面不常驻显示键盘操作提示；操作能力通过可访问性标签和实际按键保留。
- 模块内部滚动条必须隐藏，但滚轮、触控板、触屏和键盘滚动仍可使用。
- 页面主滚动条同样隐藏，以页轨和页码表达当前位置，避免右侧竖线干扰版式。
- 章节副标不得使用装饰竖线；页轨不得出现浏览器默认蓝色焦点边框，键盘焦点通过紫色形态变化保持可见。
- 标题应在语义标点处明确断行；副标位于标题下方并使用同一内容列宽，不得分散到页面另一侧。
- 中文标点、字体回退和长英文/URL 不破版。

## 技术

- HTML 可离线打开，无 CDN、远端字体和运行时构建依赖。
- 页面含 `lang=zh-CN`、viewport、标题、描述、跳转主内容与键盘焦点。
- 图片使用相对路径并在发布目录真实存在；懒加载不影响首屏。
- 尊重 `prefers-reduced-motion`；打印时隐藏导航和交互按钮。
- `↑/←`、`↓/→`、`PageUp/PageDown` 可逐屏切换，`Home/End` 可到首尾；输入框、按钮和链接获得焦点时不得劫持按键。
- 连续键盘或导航操作会取消上一段动画，不能叠加跳过章节；单次滚动动画不超过 520ms。
- 点击顶部品牌标识必须返回报告首屏，并同步页轨、页码与章节状态。
- 各章节定位后的顶部偏移、标题区高度和核心内容起始位置必须一致。
- `report.json` 与 HTML 均通过校验脚本。

## 发布

- 保存原始材料、研究源、结构化 JSON 和生成 HTML。
- 内部敏感材料先加密正文，再检查公开源码无明文。
- 工作台只保留一个稳定生产入口，不重复登记 URL。
- 构建、测试、`git diff --check` 后推送；等待 Pages 成功并验证 HTTP、标题、资源、桌面和移动端。
