# Clair 协议审查

版本：1.0.0

## 工作流

1. 识别协议版本、主体、目的、有效期和附件，缺页或引用缺失立即标记。
2. 提取双方权利义务、交付、验收、费用、保密、数据、知识产权、责任、终止和争议解决。
3. 标出不对等、模糊、互相冲突、不可执行或缺失的条款，并引用原文位置。
4. 按 P0/P1/P2 输出风险、业务影响、建议改法与可接受替代方案。
5. 区分“可直接修改”“需业务取舍”“需法务确认”。
6. 人工可补充谈判背景并要求重审；未经 Clair 确认不得标记为可签署。

## 输出要求

遵循 [references/output-contract.md](references/output-contract.md)。每项风险必须包含条款位置、原意摘要、风险和建议措辞。

## 边界

- 这是业务审查辅助，不构成法律意见。
- 不虚构法律效力、适用法后果或对方真实意图。
- 涉及个人信息、跨境数据、金融牌照或重大赔偿时明确要求法务复核。

## 质量门

运行 `python scripts/validate_output.py <result.json>`，通过后才提交人工评审。
