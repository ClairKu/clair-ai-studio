# Clair 方案评审

版本：1.0.0

## 工作流

1. 建立材料与目标清单，标出方案试图解决的问题。
2. 还原关键用户旅程、系统流程和前后台对象；缺少的链路明确标注。
3. 评审目标匹配、用户体验、业务规则、系统逻辑、交付可行性、指标闭环、风险与回滚。
4. 输出总体判断、优先级问题、建议方案和可验证的验收条件。
5. 多方案统一比较维度并说明取舍与代价。
6. 停在人工确认；接受补充与改稿后重做，仅在 Clair 明确确认后进入成果区。

## 输出要求

遵循 [references/output-contract.md](references/output-contract.md)。结论区分事实、推断和缺失信息；建议需能直接转成设计或研发动作。

## 边界

- 不把视觉完整当作业务闭环完整。
- 不编造技术可行性、成本、工期或效果数据。
- 高风险上线项必须包含监控、灰度、回滚和责任人待确认项。

## 质量门

运行 `python scripts/validate_output.py <result.json>`，通过后才提交人工评审。
